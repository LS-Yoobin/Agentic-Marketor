## Stacked Layout System (Slides 2–6)

Every comparison slide follows this exact structure, top to bottom:

```
[64px top padding]

BEFORE FOUNDING                     ← 12px, #9CA3AF, letter-spaced, uppercase
[16px gap]
"[The belief you had]"              ← 30–34px Inter Bold, White, in quotes
                                      (italic optional — emphasizes it's a thought)
[40px gap]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 1px line, #00FF7F at 60% opacity, full width minus padding

[40px gap]

AFTER                               ← 12px, #00FF7F, letter-spaced, uppercase
[16px gap]
[The truth you learned]             ← 28–32px Inter Bold, White
[ONE key word or phrase in #00FF7F] ← punch the revelation word in green
[16px gap]

[64px bottom padding]
[Handle, bottom right]
[Cat paw swipe indicator, bottom right — slides 1–6 only]
```

**The color logic:**
- BEFORE label is muted → represents the naive, past-self belief
- AFTER label is neon green → represents growth, truth, earned insight
- One word in the AFTER body text is also green → the single most important word in the revelation

## Slide-by-Slide Build Guide

---

### Slide 1 — Hook

**Label:** `CO-FOUNDER REALITY` — 12px, `#00FF7F`, letter-spaced, centered

**Copy:**
> "I thought I knew what founding meant."
> "I was wrong about almost all of it."

**Sub line (below, after breathing room):**
> "Before → After. What I actually learned."

**Layout:** Full dark background. Centered. Three stacked lines.
**Typography:**
- Line 1: 36px Inter Bold, White
- Line 2: 36px Inter Bold, White — slightly bolder weight if possible
- Sub line: 18px Inter Regular, `#9CA3AF`, italic

**Effect:** Line 2 is the gut punch. It earns the swipe because it signals honesty and humility — not bravado.

## Canva Build Order

1. Create `#0D1117` base template at 1080×1350
2. Build Slide 8 first — get `STILL HERE.` centered perfectly before anything else
3. Build Slide 7 (Save-driver) — the green hero line. Get this slide locked before touching the comparison slides
4. Build one comparison slide (Slide 2) as a template — nail the BEFORE/AFTER stacked layout with the divider line, then duplicate for slides 3–6 and swap copy
5. Build Slide 1 (Hook) last
6. Export all as PNG, 300dpi

**Canva tip for the divider line:** Use a rectangle shape, full width minus your padding (1080 - 128 = 952px wide), 1–2px height, `#00FF7F`, opacity 60%. Center it horizontally. This divider is the visual signature of the carousel — get it consistent across all comparison slides.

**Canva tip for the glow effect on AFTER section:** Add a very subtle radial gradient circle (large, ~600px diameter) behind the AFTER text, color `#00FF7F`, opacity 5–8%. This is nearly invisible but creates depth on the bottom half of each comparison slide.
