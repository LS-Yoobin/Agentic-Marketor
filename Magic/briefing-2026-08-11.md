## Agentic Flow Ideas

> Five new ideas — distinct from all prior briefing sets. Focused on novel automation for August 2026 context.

### 1. Photo → Instagram Caption Pipeline Agent
- **Area:** Content Distribution
- **What to automate:** After each morning's carousels are saved, an agent reads the brief section of each HTML file, generates 3 caption variations (short/punchy/story) optimized for Instagram, and saves them as `[filename].captions.txt` in the same directory. Zero manual captioning needed.
- **Tool/MCP:** Claude (file read + caption generation) + filesystem write
- **Time saved:** ~1.5 hrs/week — the most tedious part of the posting workflow
- **Difficulty:** Easy — files are already structured; Claude just needs to extract the brief + write captions

### 2. App Store Review Sentiment Monitor (Post-Launch)
- **Area:** Product / Customer Feedback
- **What to automate:** Daily agent fetches new App Store reviews for Bloggo (via App Store Connect RSS or unofficial API), classifies by sentiment (positive/neutral/negative) and theme (UI/AI quality/export/onboarding), and appends a summary to `output/Research/appstore-feedback-[date].md`. Flags 1-star reviews for same-day response. Immediately feeds the content idea backlog.
- **Tool/MCP:** Claude + App Store Connect API or scraper + filesystem write
- **Time saved:** ~1 hr/day post-launch — especially high-value in first 30 days
- **Difficulty:** Medium — App Store RSS is unreliable; App Store Connect API requires developer credentials

### 3. "Idea → Brief" Auto-Pipeline Agent
- **Area:** Content Creation
- **What to automate:** When a new line is added to `docs/Marketing/Idea Inbox.md`, a trigger agent reads it, generates a full content brief (hook, slides outline, format, hashtags, caption skeleton) and saves it to `output/Briefs/[date]-[slug].md`. The inbox becomes an instant content brief generator — no more blank stare at raw ideas.
- **Tool/MCP:** Filesystem watch (Claude Code hook) + Claude + filesystem write
- **Time saved:** ~30 min per idea idea — 10+ ideas/week = ~5 hrs/week
- **Difficulty:** Easy — hook into Claude Code's `UserPromptSubmit` or file-watch hook; Claude prompt is straightforward

### 4. Weekly Founder Metrics Digest
- **Area:** Analytics / Decision Support
- **What to automate:** Every Monday, agent reads manually-pasted metrics from the previous week (Instagram reach, follower delta, Notion page views, GitHub commits, beta signups) from a watched input file. Claude analyzes what moved, what didn't, and outputs a ranked "What to double down on this week" report to `Magic/metrics-[date].md`. Replaces 2 hrs of manual spreadsheet review.
- **Tool/MCP:** Claude + filesystem + optional Buffer API for auto-pull
- **Time saved:** ~2 hrs/week of unfocused metric review
- **Difficulty:** Easy (manual input) → Medium (auto-pull via Buffer/Later API)

### 5. Destination-Triggered Content Kit Generator
- **Area:** Content / Travel
- **What to automate:** When Yoobin books a trip (or manually triggers with a destination name), an agent generates a personalized "trip content kit" for that destination: 5 hook ideas, 2 carousel outlines, a Reel script idea, trending local hashtags, and suggested Bloggo blog titles. Output saved to `output/TripKits/[destination]-[date].md`. Travel prep becomes content prep automatically.
- **Tool/MCP:** Claude + WebSearch (destination trends) + filesystem write
- **Time saved:** 1–2 hrs per trip of content planning
- **Difficulty:** Easy — pure Claude + search; no API dependencies
