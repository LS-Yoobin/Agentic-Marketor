> Based on repo structure and current AI landscape as of September 2026. Five ideas building on the foundation already in `Agentic-Marketor`.

### 1. App Store Review Intelligence Agent
- **Area:** Product / Research
- **What to automate:** Weekly agent pulls App Store reviews for Bloggo (once live) and top 5 competitors (Day One, Polarsteps, Journi, Wanderlog, Google Maps). Clusters 1–3 star complaints by theme (UI, onboarding, missing feature, privacy concern). Outputs ranked "What users hate" table to `output/Research/app-store-gaps-[date].md`. Directly feeds roadmap and next week's content angles.
- **Tool/MCP:** Claude Vision API + App Store scraper (AppFollow or SensorTower API) + filesystem write
- **Time saved:** ~3 hours/week of manual review reading; guaranteed no competitor insight gets missed
- **Difficulty:** Medium — needs a paid review API (AppFollow free tier available); Claude clustering prompt is straightforward

### 2. Morning News → Content Hook Generator
- **Area:** Content Creation
- **What to automate:** Extend the existing morning briefing workflow. After STEP 1 news fetch, a micro-agent scans each headline and generates 2–3 carousel hook variations that tie the news to Bloggo or Yoobin's brand. Appends them directly to `docs/Marketing/Idea Inbox.md`. This briefing already does this manually — automate the last mile.
- **Tool/MCP:** Claude + WebSearch + filesystem write (already in this workflow)
- **Time saved:** 30 minutes/day; more importantly, never lets a viral news hook pass without a content angle captured
- **Difficulty:** Easy — add a 6th step to this existing scheduled prompt

### 3. Weekly Metrics Dashboard Agent
- **Area:** Product / Analytics
- **What to automate:** Every Sunday, agent pulls App Store Connect analytics (downloads, retention, crash rates) via App Store Connect API + Fastlane. Formats a one-page `output/metrics-[week].md` with week-over-week deltas. Sends a push notification only if a metric crosses a threshold (downloads drop >20%, crash rate >1%).
- **Tool/MCP:** App Store Connect API (Fastlane `spaceship`) + Claude formatter + push notification tool
- **Time saved:** ~2 hours/week of manual dashboard checking; zero missed regressions
- **Difficulty:** Medium — App Store Connect API requires App Store Connect API key (JSON + key ID + issuer ID); Claude formatting is easy

### 4. Founder Journal Auto-Publisher
- **Area:** Content / Building in Public
- **What to automate:** Yoobin writes a brief daily note in `Magic/journal-[date].txt` (3–5 lines, voice-memo transcribed). Agent transforms it into a polished building-in-public X/Thread draft: cleans grammar, adds a hook, reformats as a 5-post thread, saves to `output/Content/threads/[date].md`. Yoobin reviews and posts manually. Minimum effort → maximum authenticity.
- **Tool/MCP:** Claude + filesystem watch + formatter
- **Time saved:** 45 minutes/day — the gap between "I had a thought" and "I posted it" collapses
- **Difficulty:** Easy — pure Claude text transformation; no external API needed

### 5. Beta User Onboarding Feedback Loop
- **Area:** Product / User Research
- **What to automate:** When a beta user submits feedback (via TestFlight, email, or a Typeform), an agent reads the raw text, classifies it (Bug / Feature Request / Praise / Confusion), generates a plain-English summary, appends it to `output/Research/beta-feedback.md`, and creates a GitHub issue draft if it's a bug or feature request with priority score. Closes the loop between user voice and product backlog automatically.
- **Tool/MCP:** Claude + GitHub MCP (issues) + Typeform webhook or email parser + filesystem
- **Time saved:** ~2 hours/week; ensures no beta feedback falls through the cracks during launch crunch
- **Difficulty:** Medium — Typeform webhook easy; email parsing needs a simple inbound mail handler (Cloudmailin or Postmark)
