## Agentic Flow Ideas

> 5 new automation ideas for Yoobin as a solo co-founder building Bloggo + personal brand. Distinct from the April/May briefing sets.

### 1. App Store Review Sentiment Agent
- **Area:** Product / Customer Intelligence
- **What to automate:** Agent scrapes the App Store (or monitors via a review aggregator API) for new Bloggo reviews daily. Classifies each review by sentiment (positive/negative/neutral), feature category (AI quality, speed, UI, privacy, export), and urgency. Generates a weekly digest: top praise, top complaints, and 3 product actions to take. Writes the digest to Notion automatically.
- **Tool/MCP:** Puppeteer/Playwright (scrape App Store page) + Claude Vision (parse screenshots) + Notion MCP
- **Time saved:** ~2 hours/week of manual review monitoring and triage
- **Difficulty:** Medium — App Store scraping requires session handling; review parsing with Claude is straightforward

### 2. Social Proof Auto-Collector
- **Area:** Content / Marketing
- **What to automate:** Agent monitors X (Twitter), TikTok comments, and Reddit for mentions of "Bloggo" or "travel blog app" with positive sentiment. Extracts the quote, author handle, platform, and URL. Saves each one as a testimonial record in Notion (notion-personal or notion). Notifies Yoobin via push notification when something quotable arrives. Auto-formats as a screenshot-ready card.
- **Tool/MCP:** WebSearch (brand monitoring queries) + Claude (sentiment filter + formatting) + Notion MCP + PushNotification
- **Time saved:** ~3 hours/week hunting for social proof manually; turns it into a passive asset collection
- **Difficulty:** Medium — requires scheduled polling of search queries and a deduplication layer

### 3. Competitor Feature Tracker
- **Area:** Product / Competitive Intelligence
- **What to automate:** Weekly agent checks App Store pages for Day One, Polarsteps, Google Photos, and 2–3 other tracked competitors. Reads "What's New" release notes and any app description changes. Summarizes: new features shipped this week, pricing changes, and keyword shifts. Generates a weekly competitive brief saved to the output/Research folder.
- **Tool/MCP:** WebFetch (App Store URLs) + Claude (diff and summarize) + Filesystem write
- **Time saved:** ~1.5 hours/week tracking competitors manually; removes an entire recurring task
- **Difficulty:** Easy — App Store pages are public, no auth required; just fetch and parse

### 4. Weekly Metrics → Content Angle Generator
- **Area:** Content / Analytics
- **What to automate:** Every Monday, agent pulls last week's Instagram/TikTok metrics (top-performing post, follower delta, avg reach). Feeds the data to Claude, which generates 3 specific content ideas tuned to what performed best last week. Saves suggestions to Notion with context: "Last week, your privacy posts earned 3× average saves — here are 3 more to follow up with." Connects content analytics to the content creation loop.
- **Tool/MCP:** Instagram/TikTok API (or manual data paste) + Claude (pattern analysis) + Notion MCP
- **Time saved:** ~2 hours/week interpreting analytics + brainstorming follow-up content
- **Difficulty:** Medium — API access to TikTok/Instagram is gated; may need manual data input initially, then automate when credentials are in place

### 5. Founder Journal → Content Pipeline
- **Area:** Personal Brand / Content Creation
- **What to automate:** Yoobin writes a quick voice memo or text note each day (100–300 words, unfiltered). Agent transcribes or reads it, extracts the most resonant moment or insight, and converts it into 3 content formats: (1) a carousel hook, (2) a Reel script outline, (3) a tweet/X post. Saves all three to Notion-personal (YOOBIN Content Engine) with "Draft — needs polish" tag. Turns the raw daily experience into content without requiring a separate creative session.
- **Tool/MCP:** Whisper API (voice transcription) or filesystem text + Claude + Notion MCP
- **Time saved:** ~4–5 hours/week of content brainstorming replaced by 5 minutes of daily journaling
- **Difficulty:** Easy — no complex integrations needed; just Claude + Notion MCP + a consistent daily input habit
