### 1. Holiday & Cultural Moment Hook Generator
- **Area:** Content / Seasonal Marketing
- **What to automate:** Agent reads a 30-day forward calendar of holidays, cultural events, and World Cup matches. For each event, generates 3 carousel hook angles for both Yoobin and Bloggo accounts. Appends to `docs/marketing/Idea Inbox.md` with a "SEASONAL" tag and the event date. Runs every Monday morning.
- **Tool/MCP:** Claude + WebSearch (event calendar) + filesystem write
- **Time saved:** ~2 hours/week on content ideation and seasonal planning
- **Difficulty:** Easy — no complex integrations; Claude handles calendar awareness and hook generation

### 2. Weekly Investor Update Drafter
- **Area:** Fundraising / Founder Operations
- **What to automate:** Every Sunday, agent reads the week's GitHub commits (features shipped), briefing files (news context), and any metrics notes in `Magic/`. Drafts a 200-word investor update: what shipped, what's growing, one ask. Saves to `output/investor-update-[date].md` and drafts an email. Founder approves and sends.
- **Tool/MCP:** Claude + GitHub MCP (commits) + filesystem + Gmail MCP (draft)
- **Time saved:** 1.5 hours/week — removes the "I should update investors" guilt cycle
- **Difficulty:** Medium — GitHub MCP already in scope; Gmail MCP needs OAuth setup

### 3. Beta User Feedback Loop Agent
- **Area:** Product / Customer Success
- **What to automate:** Monitors App Store reviews and beta feedback email inbox. For 1-3 star reviews, drafts a personalized response within 2 hours for founder to approve+send. For feature requests, auto-appends to `docs/marketing/Idea Inbox.md` as product ideas. Runs a weekly "Top 5 Feedback Themes" report to `output/Research/feedback-[date].md`.
- **Tool/MCP:** Claude + App Store Connect API + Gmail MCP + filesystem write
- **Time saved:** 3+ hours/week on community + product feedback management
- **Difficulty:** Hard — App Store Connect API requires Apple credentials; Gmail OAuth needed; worth building post-beta launch

### 4. Content Performance Weekly Analyzer
- **Area:** Content / Analytics
- **What to automate:** Every Monday, fetches last 7 days of Instagram + TikTok performance data (views, saves, profile visits, follows). Claude analyzes: what formats performed, what hooks stopped scrolls, what flopped and why. Outputs a "double down" + "retire this format" report to `output/Research/content-performance-[date].md`. Updates content strategy decisions.
- **Tool/MCP:** Claude + Instagram Graph API + TikTok Analytics API + filesystem
- **Time saved:** 2 hours/week — removes the manual "check analytics, make a decision" loop
- **Difficulty:** Medium — both APIs require credentials but are well-documented for creator accounts

### 5. Competitive Travel App Intelligence Monitor
- **Area:** Research / Product Strategy

Extracts competitor moves, user complaints, and feature gaps. Outputs a ranked "Competitive Intelligence Brief" to `output/Research/competitive-[date].md`.
