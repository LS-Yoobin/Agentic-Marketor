### 1. Content Performance Tracker Agent

- **Area:** Content / Analytics
- **What to automate:** After each post goes live, agent polls the Instagram Basic Display API or Meta Graph API weekly, pulls engagement metrics (likes, saves, shares, reach, profile visits) for every Bloggo and Yoobin post, and writes a `output/analytics/performance-log-[date].csv`. Every Sunday, Claude analyzes the CSV to identify top-performing formats, hook types, and posting times — outputs a "What Worked This Week" brief to `Magic/performance-[date].md`.
- **Tool/MCP:** Meta Graph API (IG Business Account required) + filesystem + Claude analysis
- **Time saved:** 2 hours/week of manual analytics review; surfaces what to repeat vs. retire
- **Difficulty:** Medium — Meta Graph API requires Business account setup; Claude analysis layer is straightforward once data flows in

### 2. App Store Review Intelligence Agent

- **Area:** Product / Customer Feedback
- **What to automate:** Weekly agent pulls Bloggo's App Store reviews via App Store Connect API (or AppFollow if faster to set up), classifies reviews by sentiment and theme (positive/negative/feature request/bug), clusters by topic, and appends to `output/Research/reviews-[date].md`. Always ends with "Top 3 Action Items" — each item either goes to a GitHub issue or to `docs/marketing/Idea Inbox.md`. Closes the loop between users and roadmap automatically.
- **Tool/MCP:** App Store Connect API or AppFollow API + Claude + filesystem + GitHub MCP (optional)
- **Time saved:** 3 hours/week of manual feedback processing
- **Difficulty:** Medium — App Store Connect needs API key setup; once wired, fully automatic

### 3. Weekly Content Priority Ranker

- **Area:** Content / Productivity
- **What to automate:** Every Sunday, agent reads the full YOOBIN Content Engine and Bloggo Content Engine idea backlogs from Notion, scores each idea by: (a) alignment to that week's content trends (from the Monday briefing), (b) time since similar content was posted, and (c) estimated viral potential based on hook type. Outputs a ranked "Top 5 to Execute This Week" list, pinned as a Notion callout block at the top of each content engine. Eliminates the weekly "what should I post?" decision.
- **Tool/MCP:** Notion MCP (read + write) + Claude scoring + WebSearch (trend alignment)
- **Time saved:** 1.5 hours/week of content planning; more importantly, removes decision fatigue every Monday morning
- **Difficulty:** Easy — once Notion MCP write is fixed; Claude scoring is straightforward

### 4. Investor & Press Radar Agent

- **Area:** Business Development / Fundraising
- **What to automate:** Weekly agent searches for: new travel app funding rounds, App Store feature announcements in travel/lifestyle, Product Hunt launches in adjacent categories (AI journaling, travel memory, photo organization), and any press coverage of Polarsteps, Day One, or Journey competitors. Generates a "Market Temperature Report" to `output/Research/investor-radar-[date].md`. Helps Yoobin time fundraising conversations and spot positioning opportunities before competitors do.
- **Tool/MCP:** WebSearch + Claude + filesystem write
- **Time saved:** 2 hours/week of manual market scanning
- **Difficulty:** Easy — pure WebSearch + Claude synthesis; no external API required

### 5. End-of-Day Founder Journal → Content Pipeline

- **Area:** Personal Productivity / Building in Public
- **What to automate:** Each evening, a 3-question Founder Check-In drops into a watched file (`Magic/journal-today.txt`): "What shipped? What blocked you? What did you realize?" Agent reads the file, stores a dated entry to `Magic/journal-log.md`, and every Sunday synthesizes the week's journal entries into: (a) 5 tweet drafts for X, (b) one carousel hook for Instagram, and (c) one LinkedIn post — all saved to `output/Content/weekly-thread-[date].md`. Turns daily reflection into compounding content automatically.
- **Tool/MCP:** Filesystem watch + scheduled trigger + Claude + content formatter
- **Time saved:** 1 hour/week of content drafting; more importantly, builds a compounding story asset that compounds for years
- **Difficulty:** Easy — file watch and scheduled Claude trigger; no external API needed
