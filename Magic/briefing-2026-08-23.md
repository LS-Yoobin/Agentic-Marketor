Travelers are reviewing their summer trip photos right now — the highest-intent moment for Bloggo discovery. Content showing "turn your summer photos into a blog" has maximum relevance this week.

8. **Proof-based content earns trust** — Audiences in 2026 demand evidence: real metrics, real demos, real before/after. "Show don't tell" is now a baseline expectation, not a best practice. Bloggo demo content (screen recordings, real trip blogs) will outperform concept copy.

### 1. End-of-Summer Content Surge Agent
- **Area:** Content / Seasonal Marketing

Runs once, queues to Buffer/Later, notifies Yoobin for approval. Zero manual brief writing.

- **Difficulty:** Medium — needs Buffer API credentials; Claude prompt already has full brand context

### 2. App Store Review Sentiment Tracker
- **Area:** Product / Customer Intelligence
- **What to automate:** After launch, an agent checks Bloggo's App Store reviews daily (via AppFollow API or manual paste). Extracts top 3 positive themes, top 3 negative themes, and any feature requests. Appends a daily `output/Research/app-store-sentiment-[date].md` file. Flags anything with 3+ occurrences to the Idea Inbox automatically. Turns user feedback into a live roadmap signal.
- **Tool/MCP:** Claude + AppFollow API (or WebFetch for App Store page) + filesystem write + Notion MCP (Idea Inbox)
- **Time saved:** 2–3 hours/week of manual review reading; more importantly, prevents feedback blind spots
- **Difficulty:** Medium — AppFollow has a free API tier; parsing and summarizing is Claude-native

### 3. Personal Brand Performance Scorecard Agent
- **Area:** Content / Personal Brand
- **What to automate:** Weekly agent reads last 7 days of content output (carousel files, output folder), checks which pieces were actually published (by reading a simple `published-log.md` that Yoobin updates), and generates a "what got made vs. what got posted" gap report. Tracks content velocity, publish rate, and flagged high-priority pieces not yet posted. Sent as a Sunday evening briefing addendum.
- **Tool/MCP:** Claude + filesystem read + Notion MCP (read published status) + scheduled cron
- **Time saved:** 1 hour/week of self-auditing; prevents content sitting in output/ folder unpublished for weeks
- **Difficulty:** Easy — pure file reading + Claude analysis; no external API needed

### 4. Traveler Persona Research Agent (Pre-Launch User Intelligence)
- **Area:** Product Strategy / Research
- **What to automate:** Weekly agent searches Reddit (r/solotravel, r/travel, r/digitalnomad) for posts mentioning "camera roll," "travel photos," "photo backlog," or "travel journal." Extracts verbatim quotes from real travelers describing their memory pain points. Formats top 10 quotes into `output/Research/persona-quotes-[date].md`. Direct input for ad copy, App Store description, and persona refinement.
- **Tool/MCP:** Claude + WebSearch (Reddit search) + filesystem write
- **Time saved:** 3 hours/week of manual Reddit research; produces authentic voice-of-customer copy fodder
- **Difficulty:** Easy to Medium — WebSearch can hit Reddit threads; Claude extracts and formats

### 5. Founder Newsletter Auto-Draft Agent
- **Area:** Content / Distribution
- **What to automate:** Using each week's morning briefing as input, an agent drafts a 300-word "building in public" newsletter update for Yoobin's email list (Beehiiv or ConvertKit). Includes: one thing shipped, one thing learned, one honest struggle, and a Bloggo update. Saves draft to `output/Content/newsletter-[date].md` for review and send.
