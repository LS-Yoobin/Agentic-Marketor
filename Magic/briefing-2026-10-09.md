## Agentic Flow Improvements

Five concrete automation ideas for Yoobin's work and life:

### 1. Content Performance Feedback Loop Agent
- **Area:** Content Distribution
- **What to automate:** Weekly agent pulls Instagram Insights (via API or manual input), analyzes which carousel format/hook type earned the most saves, reach, and profile visits. Outputs a ranked report with specific lessons ("Fear hooks earned 3× more saves this week than Story hooks"), updates a running `content-performance.md` file, and uses the data to weight next week's carousel topic selection.
- **Tool/MCP:** Claude + Instagram Basic Display API + filesystem
- **Time saved:** 3–4 hours/week in manual performance review and next-week planning
- **Difficulty:** Medium — Instagram API scopes are limited; manual paste-in of stats works as v1

### 2. Daily Health + Focus Protocol Agent
- **Area:** Health / Habits
- **What to automate:** Every morning at 6:30 AM, agent sends a structured 3-item check-in via Slack/SMS: (1) sleep quality (1–10), (2) one intention for the day, (3) one thing to avoid today. Logs all responses to `habits-log.md`. Weekly summary shows correlation between reported sleep quality and productivity (carousel output, commits). 
- **Tool/MCP:** Claude + CronCreate + Slack MCP or Twilio API + filesystem
- **Time saved:** 30 min/day in mental overhead; compounding benefit from habit tracking over 90 days
- **Difficulty:** Easy — CronCreate already works; add a Slack webhook

### 3. App Store Review Monitor + Response Agent
- **Area:** Product / Customer Feedback
- **What to automate:** Daily agent polls the App Store Connect API for new Bloggo reviews, classifies each by sentiment and theme (bug, feature request, praise, privacy concern), routes bug-adjacent reviews to a GitHub issue draft, and prepares a response draft for any 1–3 star review within 24 hours. Outputs a weekly digest of feature requests ranked by mention frequency.
- **Tool/MCP:** Claude + App Store Connect API + GitHub MCP + filesystem
- **Time saved:** 5–6 hours/week on review monitoring and response — currently a manual task that delays critical product feedback
- **Difficulty:** Medium — App Store Connect API requires App Store Connect credentials; review response drafts require human approval before posting

### 4. Expense + Runway Tracker Agent
- **Area:** Finance
- **What to automate:** Weekly agent pulls transactions from connected bank/card (Mercury or Brex API), categorizes spend by type (SaaS, contractor, travel, ads), calculates current monthly burn rate, updates a `runway-tracker.md` with current runway in months, and flags any subscription charges above $50 that haven't been reviewed in 30 days. One-line runway status added to daily briefing header.
- **Tool/MCP:** Claude + Mercury API or Plaid API + filesystem + CronCreate
- **Time saved:** 2–3 hours/week on manual expense review and runway math
- **Difficulty:** Medium — requires bank API credentials or Plaid integration; Mercury has a developer-friendly API

### 5. Launch Countdown + Milestone Pulse Agent
- **Area:** Product Development
- **What to automate:** Tracks Bloggo's App Store submission/launch timeline. Every Monday morning, agent checks off items from the V1 launch checklist (App Store screenshots, privacy policy, ASO keywords, TestFlight beta group size), surfaces the top 3 blockers, and generates a one-paragraph "state of the launch" update ready to post as a building-in-public thread. Also pings Yoobin if any checklist item hasn't been updated in >7 days.
- **Tool/MCP:** Claude + filesystem (launch checklist .md) + CronCreate + Notion MCP
- **Time saved:** 1–2 hours/week on launch coordination overhead; more valuable: prevents launch-blocking items from going unnoticed
- **Difficulty:** Easy — fully text-file based; Notion MCP can write directly to the Bloggo Content Engine
