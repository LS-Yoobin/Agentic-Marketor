## Agentic Flow Improvements

### 5 Concrete Automation Ideas for Yoobin

**1. Content Distribution Automator**
- **Area:** Content
- **What to automate:** After carousels are generated and approved, automatically queue them to Instagram and TikTok via scheduling APIs. Right now carousels sit in `output/Carousels/` and require manual upload.
- **Tool/MCP:** Buffer API or Later API (via HTTP MCP or custom integration); alternatively Instagram Graph API directly
- **Time saved:** 30–45 min/day of manual copy-paste, caption writing, and upload scheduling
- **Difficulty:** Medium — requires Instagram Business account + API access; Buffer/Later have simpler OAuth flows

---

**2. App Store Review Intelligence Agent**
- **Area:** Product / Customer Feedback
- **What to automate:** Daily scrape of Bloggo's App Store reviews (using App Store Connect API or Appbot), categorize by sentiment and feature request, and send a weekly digest with top themes, verbatim quotes, and priority signals
- **Tool/MCP:** App Store Connect API + a lightweight classification agent (Claude Haiku 4.5 for cost) + Notion MCP to push results to a "User Feedback" database
- **Time saved:** 2–3 hours/week of manual review reading; replaces need to remember to check
- **Difficulty:** Medium — App Store Connect API requires Apple credentials setup; classification is straightforward

---

**3. Morning Portfolio + Metrics Tracker**
- **Area:** Finance / Product
- **What to automate:** Extend the daily briefing to pull real RevenueCat subscription metrics (MRR, new subscribers, churn) and paper trading portfolio (or real brokerage via Alpaca API) and surface them alongside news. One dashboard view, every morning.
- **Tool/MCP:** RevenueCat API (HTTP MCP) + Alpaca API for portfolio tracking + this briefing workflow
- **Time saved:** 15–20 min/day of opening multiple dashboards; all in one place
- **Difficulty:** Easy-Medium — RevenueCat and Alpaca both have clean REST APIs; just needs API keys in `.env`

---

**4. Founder Content Idea Recycler**
- **Area:** Content
- **What to automate:** Every Sunday, scan the past week's top-performing content (via Instagram Insights API), identify what resonated, and auto-generate 5 remix ideas for next week — same angle, different format or hook. Prevents creative fatigue and compounds what's already working.
- **Tool/MCP:** Instagram Graph API (performance data) + Claude Sonnet 5 (remix generation) + write results to `docs/Marketing/Idea Inbox.md`
- **Time saved:** 1 hour/week of content planning; keeps ideas compounding instead of starting from zero each week
- **Difficulty:** Medium — Instagram API requires app review for insight scopes; content generation is straightforward

---

**5. App Store Keyword Rank Monitor**
- **Area:** Growth / ASO
- **What to automate:** Weekly automated check of Bloggo's App Store keyword rankings for target terms ("travel blog app", "AI travel diary", "photo to blog", "trip journal automatic") using an ASO API. Alert when rankings shift ±5+ positions, or when a competitor enters the top 5 for a tracked keyword.
