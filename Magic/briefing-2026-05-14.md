## Agentic Flow Ideas

> Based on repo structure and Yoobin's profile as a solo co-founder building Bloggo + a personal brand.

### 1. Travel Expense Tracker Agent
- **Area:** Finance / Founder Travel
- **What to automate:** When Yoobin travels, agent reads photos of receipts (vision → OCR → category tag). Auto-logs each receipt to a CSV or Notion DB as a founder expense, separates business vs. personal, and generates a weekly "travel expense summary." No manual entry, no spreadsheet.
- **Tool/MCP:** Claude Vision API + filesystem write + Notion MCP
- **Time saved:** ~2 hours/week during travel periods; zero friction vs. current manual process
- **Difficulty:** Medium — needs Claude Vision prompt tuned to receipt parsing + Notion MCP write access

### 2. GitHub Issue → Content Ideas Pipeline
- **Area:** Product / Content
- **What to automate:** When a new GitHub issue or beta feedback note is added (bug, feature request, question), an agent summarizes it in plain English and appends it to `docs/marketing/Idea Inbox.md` as a content idea. User pain = content gold. Turns product feedback into an automatic content backlog.
- **Tool/MCP:** GitHub MCP (issues) + Claude + filesystem write
- **Time saved:** ~1.5 hours/week of manual feedback review
- **Difficulty:** Easy — GitHub MCP already in scope; just needs a trigger + Claude summarizer prompt

### 3. Daily Founder Health Check Agent
- **Area:** Health / Habits
- **What to automate:** Each morning, a 3-question log drop into a watched file (`Magic/health-log.txt`): sleep hours, energy level (1–5), exercise (yes/no). Agent tallies weekly averages every Sunday and writes a plain-English "Founder Health Score" to `Magic/health-[date].md`. Flags when 3+ consecutive low-sleep days correlate with low output.
- **Tool/MCP:** Filesystem watch + Claude analysis + scheduled trigger
- **Time saved:** 20 minutes/day of self-tracking friction; more importantly, surfaces patterns that would otherwise go unnoticed
- **Difficulty:** Easy — file watch + minimal Claude analysis loop

### 4. Competitive Intelligence Monitor
- **Area:** Research / Product Strategy
- **What to automate:** Weekly agent searches App Store reviews for top travel journaling competitors (Polarsteps, Day One, Journey). Extracts 1-star and 2-star complaints, clusters by theme, and outputs a ranked "Competitor Weakness Report" to `output/Research/competitor-gaps-[date].md`. Directly feeds Bloggo's differentiation copy and roadmap prioritization.
- **Tool/MCP:** Claude + WebSearch + App Store review scraper (or manual paste) + filesystem write
- **Time saved:** ~3 hours/week of manual research
- **Difficulty:** Medium — scraping App Store reviews requires a workaround (manual paste or third-party API); Claude analysis layer is easy

### 5. Social Caption + Hashtag Scheduler Agent
- **Area:** Content Distribution
- **What to automate:** After each morning's carousels are generated, agent analyzes that week's trending hashtags for travel and founder content, appends an optimized caption + hashtag set to each carousel's `.brief` section, and queues posts to a scheduling tool (Buffer or Later API). Content goes from HTML file to scheduled post in one automated step.
- **Tool/MCP:** Claude + WebSearch (trending hashtags) + Buffer API or Later API + filesystem
- **Time saved:** ~4 hours/week — the single highest-leverage automation for distribution
- **Difficulty:** Medium — depends on Buffer or Later API credentials; Claude hashtag research layer is straightforward
