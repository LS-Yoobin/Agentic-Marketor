- **Area:** Product Strategy / Research

Output: `output/Research/competitor-intel-[date].md` with a "What to steal" and "What to avoid" table.
- **Tool/MCP:** App Store Connect API or scraper + Claude analysis + filesystem
- **Time saved:** ~3 hours/week of competitive intelligence
- **Difficulty:** Medium — scraping competitor App Store reviews is publicly accessible but needs rate limiting

### 3. **Founder Energy Log → Weekly Reflection Agent**
- **Area:** Health / Personal Productivity
- **What to automate:** Each evening, Yoobin drops 3 bullets into a watched file (e.g., `Magic/daily-log.md`): energy level (1-5), biggest win, biggest blocker. Agent runs every Sunday morning, aggregates 7 days of logs, and produces a plain-English weekly reflection: what drained energy, what momentum looks like, what to change next week. Outputs to `Magic/reflection-[date].md`.
- **Tool/MCP:** Filesystem watch + Claude analysis + file write
- **Time saved:** ~1.5 hours/week of journaling + pattern recognition time
- **Difficulty:** Easy — pure filesystem + Claude analysis loop

### 4. **User Feedback → Feature Brief Agent**
- **Area:** Product Development / Customer Feedback
- **What to automate:** Post-launch: agent collects TestFlight feedback, App Store reviews, and any DM-sourced feedback (pasted into a raw feedback file). Feeds directly into sprint planning.
- **Tool/MCP:** TestFlight API (limited) + filesystem + Claude clustering + Notion MCP write
- **Time saved:** ~2.5 hours/week post-launch
- **Difficulty:** Medium — depends on where feedback lives; easiest if feedback is manually pasted into a watched file

### 5. **Trip Idea → Travel Content Brief Agent**

Agent: (a) researches the destination's hidden spots, food, culture using WebSearch, (b) generates 3 Reel concepts with hooks and scripts, (c) generates 1 carousel idea with full copy, (d) outputs a `output/Content/trip-brief-[destination]-[date].md`.
