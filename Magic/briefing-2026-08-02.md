## Agentic Flow Ideas

> Based on repo structure, current workflows, and Yoobin's profile as solo co-founder building Bloggo + personal brand. Five ideas not previously covered in earlier briefings.

### 1. App Store Review Intelligence Agent
- **Area:** Product / Research
- **What to automate:** Weekly agent pulls 1-star and 2-star reviews from top competitor apps (Polarsteps, Day One, Journey, Notchback) using a third-party review API or Apptopia. Claude clusters complaints by theme (e.g. "no export," "doesn't organize by trip," "bad AI captions") and outputs a ranked competitor weakness report to `output/Research/competitor-gaps-[date].md`. Top 3 gaps become inputs for next day's content ideas and product roadmap.
- **Tool/MCP:** WebSearch (scrape review summaries) + Claude analysis + filesystem write
- **Time saved:** ~3 hours/week of manual review reading
- **Difficulty:** Medium — App Store doesn't have a public review API; workaround is manual paste or third-party (Apptopia/Sensor Tower trial)

### 2. Beta Waitlist Persona Extractor
- **Area:** Product / Marketing
- **What to automate:** When new beta signups arrive (from bio link or TestFlight), an agent parses the signup form responses or email replies, extracts quoted pain points, maps each to a persona type (Overwhelmed Traveler, Occasional Blogger, Travel Influencer, Memory Keeper), and appends the result to a Notion database. Shows which persona is converting, which informs content prioritization.
- **Tool/MCP:** Email tool (already in repo) + Claude + Notion MCP
- **Time saved:** ~2 hours/week; more importantly surfaces real user language for ad copy
- **Difficulty:** Easy — email parsing + Claude classification is a one-prompt workflow

### 3. Weekly Founder Health Snapshot
- **Area:** Health / Habits
- **What to automate:** Every Sunday, agent prompts Yoobin to drop a 3-line check-in (sleep avg, energy level 1–5, shipped something yes/no) into a watched file. Claude calculates weekly scores, flags if 3+ consecutive low-energy weeks correlate with low output velocity, and writes `Magic/health-[date].md`. On positive weeks, agent pulls a travel destination quote from the repo as a "reward."
- **Tool/MCP:** Filesystem watch + Claude + scheduled trigger
- **Time saved:** 15 minutes/day of manual self-tracking friction; more importantly creates a performance feedback loop
- **Difficulty:** Easy — pure Claude + filesystem; no external API needed

### 4. Content Performance Feedback Loop
- **Area:** Content Distribution
- **What to automate:** After 48 hours, agent checks Instagram Insights via API for each posted carousel (saves, reach, shares). If a carousel outperforms the 7-day avg by >20%, agent automatically generates a variation post ("remix the winner") and saves it to `output/Carousels/remixes/`. If underperforms, agent logs what went wrong to the Idea Inbox as a dead hypothesis.
- **Tool/MCP:** Instagram Graph API + Claude + filesystem write
- **Time saved:** ~2 hours/week of manual performance review; closes the content feedback loop the current workflow is missing
- **Difficulty:** Hard — requires Instagram Graph API setup and approved developer app access

### 5. Travel Finance Tracker (Receipt → Notion)
- **Area:** Finance / Founder Travel
- **What to automate:** When Yoobin travels, agent accepts a photo of a receipt via a Telegram bot (or email attachment). Claude Vision extracts amount, vendor, category, and currency, converts to USD, and appends the row to a Notion table tagged as "Business" or "Personal." Weekly summary report auto-generated every Sunday to `Magic/expense-[date].md`. Prepares for tax season automatically.
- **Tool/MCP:** Claude Vision (image input) + Notion MCP + Telegram bot or email tool
- **Time saved:** ~2 hours/week during travel; zero receipt data entry going forward
- **Difficulty:** Medium — needs Telegram bot or email trigger; Claude Vision prompt for receipts is straightforward
