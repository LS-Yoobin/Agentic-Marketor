- **What to automate:** Each morning before the briefing runs, a sub-agent queries 5 RSS feeds (TechCrunch, Indie Hackers, App Store news, TravelTech Insider, WallStreetBets) and surfaces only the 3 most Bloggo-relevant items. - **Time saved:** ~45 min/week of manual research scanning
- **Difficulty:** Easy — already have the search tools; just needs a curation prompt + scheduled trigger

### 2. Instagram Caption Finisher
- **Area:** Content Creation
- **What to automate:** After carousels are generated, a second-pass agent reads each carousel's `.brief` block and auto-generates 3 caption variations (short/punchy, story-driven, question-starter) formatted for Instagram with hashtags included. Drops them into a `Captions/[date].md` file alongside the HTML files.
- **Tool/MCP:** Claude API + filesystem read/write
- **Time saved:** ~2 hours/week of caption writing
- **Difficulty:** Easy — pure Claude API prompt over existing file content

### 3. Founder Journal → Idea Inbox Pipeline
- **Area:** Personal Productivity / Content
- **What to automate:** Yoobin drops raw daily notes into a watched file (`Magic/journal-today.md`) — even just bullets ("shipped X, felt Y, learned Z"). An agent reads it each evening, extracts 2–3 content ideas with hook lines, and appends them to `docs/Marketing/Idea Inbox.md` with a date stamp. Never lose a raw insight again.
- **Tool/MCP:** Filesystem watch/read + Claude API + file append
- **Time saved:** ~1.5 hours/week of idea capture that currently gets lost
- **Difficulty:** Easy — simple Claude prompt + two file ops; no external APIs needed

### 4. Alpaca Paper Trading Auto-Executor
- **Area:** Finance / Stock Simulation
- **What to automate:** Connect the daily stock simulation to Alpaca's paper trading API. Each morning, the briefing agent sends BUY/SELL/HOLD signals to Alpaca paper account automatically. Track real-time P&L via Alpaca dashboard rather than manual estimates. When 30-day threshold + Sharpe >1 is hit, the agent flags graduation readiness for Yoobin's review.
- **Tool/MCP:** Alpaca Paper Trading REST API + Claude analysis + filesystem write
- **Time saved:** ~1 hour/week of manual portfolio tracking; eliminates estimation errors
- **Difficulty:** Medium — requires Alpaca API key + REST calls; no complex auth

### 5. App Store Review Sentiment Monitor
- **Area:** Product / Customer Feedback
- **What to automate:** Post-launch, poll App Store Connect RSS feed or API for new Bloggo reviews daily. For 1–2 star reviews: draft a warm, specific response in Bloggo brand voice for Yoobin to approve with one click.
