### 1. Instagram Post Auto-Scheduler from Carousel Output

- **Area:** Content Distribution
- **What to automate:** After each morning carousel run, an agent scans `output/Carousels/[TODAY]/`, reads each `.brief` box inside the HTML files, extracts the caption note and Notion destination, and queues a draft post in Buffer or Later with the correct caption, hashtags, and a scheduled time (7 AM, 12 PM, 6 PM rotation). - **Estimated time saved:** 3–4 hours/week of manual scheduling and caption writing
- **Difficulty:** Medium — requires Buffer or Later API credentials; the agent's file-reading and caption-extraction logic is straightforward

### 2. Weekly Bank Statement → Founder Expense Report

- **Area:** Finance / Bookkeeping
- **What to automate:** Drop a bank statement PDF into a watched folder (`Magic/bank-statements/`). Agent parses it, categorizes each transaction as Business or Personal (using a rules file you define once), flags uncategorized items for manual review, and writes a clean weekly expense summary to `output/Finance/expenses-[week].md` with total spend by category, runway estimate, and a "founder burn rate" number.
- **Tool/MCP:** Claude Vision API (PDF parsing) + filesystem write + optional Notion MCP for logging
- **Estimated time saved:** 2–3 hours/month of manual bookkeeping; more importantly, gives real-time runway visibility a solo founder rarely has
- **Difficulty:** Medium — PDF parsing needs a robust prompt; category rules file is a one-time setup cost

### 3. Daily Voice Note → Founder Journal Auto-Log

- **Area:** Health / Habits / Personal Productivity
- **What to automate:** Each evening, Yoobin records a 60–90 second voice note into a watched folder (via Whisper or iOS Shortcuts → Dropbox). Agent transcribes it, extracts 3 things: what got done today, what's blocked, how the energy level felt. Appends a structured entry to `Magic/founder-journal-[month].md`. Every Sunday, generates a weekly summary with patterns — high-energy days, repeated blockers, streak of wins.
- **Tool/MCP:** Whisper API (transcription) + Claude (extraction + summary) + filesystem write
- **Estimated time saved:** Replaces manual journaling (30+ min/week) with a 60-second habit. The weekly pattern summary is something most founders never see.
- **Difficulty:** Easy — transcription + Claude analysis is a solved pipeline; the only friction is building the iOS Shortcut to capture the audio

### 4. Competitor App Store Review Miner

- **Area:** Research / Product Strategy
- **What to automate:** Every Monday, agent searches for 1-star and 2-star reviews of the top 5 travel journaling competitor apps (Polarsteps, Day One, Journey, Polarsteps, Google Photos). Extracts the most common complaints, clusters them by theme (missing features, privacy concerns, UX friction, performance), and appends a ranked "Competitor Weakness Report" to `docs/Marketing/Idea Inbox.md` as ready-to-use content ideas. Competitor pain = Bloggo content gold.
- **Tool/MCP:** Claude + WebSearch + App Store review scraper API (AppFollow, AppBot, or Sensor Tower free tier) + filesystem write
- **Estimated time saved:** 3–4 hours/week of manual competitive research; directly generates content ideas and roadmap signals
- **Difficulty:** Medium — review scraping requires a third-party API or manual paste workflow; the analysis and idea-generation layer is easy

### 5. "Strategic Implication" News Filter Agent

- **Area:** Research / Founder Clarity
- **What to automate:** After each morning briefing is generated, a second-pass agent reads the World & Tech News section, filters for only the stories relevant to Bloggo's product, market, or positioning, and writes one "strategic implication" sentence per relevant story. - **Difficulty:** Easy — pure Claude text analysis over a file that already exists in the repo; no external APIs needed
