## Agentic Flow Ideas

> Based on the Agentic-Marketor repo structure: `Workflows/`, `output/`, `Magic/`, `docs/Marketing/`, and your profile as a solo co-founder building Bloggo + personal brand.

### 1. **Multi-Platform Content Repurposer Agent**
- **Area:** Content Creation / Distribution
- **What to automate:** After every carousel HTML is generated and saved to `output/Carousels/[date]/`, an agent reads the `.cap-txt` (Instagram + TikTok captions already in the HTML file), extracts the content brief, and auto-generates: (a) a Twitter/X thread, (b) a LinkedIn post, (c) a reformatted TikTok script, (d) a Notion content brief card. One run → 4 distribution formats without any manual rewriting.
- **Tool/MCP:** Claude API (`claude-sonnet-4-6`) + Notion MCP write + filesystem reads of `output/Carousels/` HTML files
- **Time saved:** ~3 hours/week
- **Difficulty:** Medium — needs a regex/parser to extract `.cap-txt` blocks from HTML + Notion MCP write access

### 2. **Founder Voice Journal → Idea Inbox Pipeline**
- **Area:** Personal Productivity / Content
- **What to automate:** Yoobin writes a raw daily note (even just voice-to-text bullets: "shipped X, felt Y, learned Z about App Store") into a watched folder (`Magic/journal-[date].md`). Agent transforms each entry into 3 content idea cards with hooks, pillar tags, and platform recommendations, then appends them to `docs/Marketing/Idea Inbox.md`. No insight gets lost. The morning briefing then reads the Idea Inbox before generating carousels, so Yoobin's own observations directly bias the AI's content choices.
- **Tool/MCP:** Filesystem watch (inotify / launchd cron) + Claude API + file append to Idea Inbox
- **Time saved:** ~2 hours/week of "idea capture" time
- **Difficulty:** Easy — straightforward prompt + file read/write loop; no external APIs needed

### 3. **App Store Review Monitor + Response Draft Agent**
- **Area:** Product / Customer Feedback Loops (post-launch)
- **What to automate:** Once Bloggo is live, an agent polls App Store Connect API daily for new reviews. For 1–2 star reviews it drafts a warm, specific human-sounding response for Yoobin to approve and post. For 4–5 star reviews it extracts the praised feature and appends it to `output/Content/User Love.md` — a live bank of authentic user language for future marketing copy. Patterns across reviews are summarised weekly into `Magic/app-store-pulse-[date].md`.
- **Tool/MCP:** App Store Connect API (JWT auth) + Claude API + filesystem writes
- **Time saved:** ~2.5 hours/week post-launch
- **Difficulty:** Medium — App Store Connect API requires App Store Connect key; the Claude summarisation and file-write parts are trivial

### 4. **Performance Pattern Learner (Winning Hooks Tracker)**
- **Area:** Social Media Distribution / Growth
- **What to automate:** Each week, Yoobin pastes the top 5 performing Instagram posts (by saves + shares — a 30-second manual copy-paste) into a `Magic/metrics-[date].md` file. An agent analyses which hook types, angles, and slide structures generated the highest saves — and writes its conclusions to `docs/Marketing/Winning Patterns.md`. The carousel generator workflow reads this file before selecting hooks for the week. Over time, the system learns what resonates with Yoobin's specific audience.
- **Tool/MCP:** Claude API analysis + filesystem read/write + carousel generator integration (already in `Workflows/carousel-generator.md`)
- **Time saved:** ~1.5 hours/week of manual performance review
- **Difficulty:** Easy — the data input is manual (paste metrics) but the analysis and output are fully automated

### 5. **Weekly Finance + Runway Snapshot Agent**
- **Area:** Finance / Founder Ops
- **What to automate:** Each Sunday, agent reads a simple CSV (`Magic/expenses-[YYYY-MM].csv`) where Yoobin logs weekly spending. Combines with the paper portfolio simulation P&L and any Stripe revenue (post-launch) to output a 6-line plain-English `Magic/finance-[date].md` summary: weekly burn rate, MRR delta, estimated runway in weeks, and one-sentence "action flag" if burn spikes above threshold. No spreadsheet. No dashboard. Just a number you can act on.
- **Tool/MCP:** CSV reader + Claude API analysis + filesystem write; post-launch add Stripe API
- **Time saved:** ~1 hour/week
- **Difficulty:** Easy (CSV route) — can be live this week. Medium if adding Stripe API.
