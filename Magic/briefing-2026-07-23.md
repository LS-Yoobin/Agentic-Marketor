Distribution (not building) is now the constraint for solo founders.

## Agentic Flow Ideas

> Based on Bloggo's current stage (pre-launch, App Store submission pending) and Yoobin's solo founder workflow. Distinct from previous briefing sets.

### 1. Content Gap Detector
- **Area:** Content / Social Media
- **What to automate:** Agent runs weekly to check last 7 days of output — if no carousels were generated, no Notion pushes, or the briefing wasn't run, it sends a Slack/email alert with a one-line prompt to restart the workflow. Prevents the silent 2-month content droughts that happened May → July. Also surfaces what topics have been covered most vs. least in the past 30 days to avoid repetition and find gaps.
- **Tool/MCP:** Filesystem read + Claude analysis + email/Slack webhook
- **Time saved:** Not time savings — prevents revenue-impacting content gaps entirely. The 70-day gap from mid-May to now cost brand momentum. One 15-minute build prevents weeks of drift.
- **Difficulty:** Easy — reads output folder, checks file dates, fires alert

### 2. App Store Review Monitor + Response Drafter
- **Area:** Product / Customer Feedback
- **What to automate:** After Bloggo launches, an agent monitors new App Store reviews daily (via App Store Connect API or a scraper). For each new review: summarizes the sentiment, extracts the core feature request or complaint, appends to `output/Research/app-store-feedback-[date].md`, and drafts a response for 1-3 star reviews. Yoobin approves and posts. Turns review triage from a chore into a 5-minute daily checkpoint.
- **Tool/MCP:** App Store Connect API + Claude analysis + filesystem write
- **Time saved:** 3-4 hours/week post-launch; more importantly ensures no review goes unanswered (which kills App Store conversion)
- **Difficulty:** Medium — App Store Connect API needs setup; review drafting is straightforward Claude prompting

### 3. Weekly Content Performance Digest
- **Area:** Content / Analytics
- **What to automate:** Every Sunday, agent pulls engagement data from Instagram (via Meta Basic Display API), summarizes top 3 performing posts from the week (by saves + shares, not likes), identifies which hook type performed best, and outputs a 1-page digest to `Magic/performance-[date].md`. Over 4-6 weeks, patterns emerge: which carousel angles work, which CTAs convert, which slide count gets swiped through vs. dropped. No more guessing.
- **Tool/MCP:** Instagram Graph API + Claude analysis + filesystem write
- **Time saved:** 2 hours/week of manual analytics; replaces spreadsheet-based tracking
- **Difficulty:** Medium — Instagram Graph API requires a Facebook developer app setup; analysis layer is easy

### 4. Competitor ASO Tracker
- **Area:** Research / App Store Optimization
- **What to automate:** Bi-weekly agent searches App Store rankings for keywords Bloggo targets ("travel blog app", "travel journal app", "travel diary iOS"). Tracks top 10 results, noting any rank changes for key competitors (Polarsteps, Day One, Journey). Outputs a ranking snapshot to `output/Research/aso-tracker-[date].md` with a "what changed and why" note. Catches when a competitor runs a paid UA push or a keyword surge before it starts affecting Bloggo.
- **Tool/MCP:** Claude + WebSearch (App Store rankings) + filesystem write
- **Time saved:** 2 hours/week of manual ASO research; more importantly provides early warning on competitive moves
- **Difficulty:** Easy — App Store rankings are public; this is a Claude + WebSearch pipeline with minimal tooling

### 5. Beta User Onboarding Email Sequence Generator
- **Area:** Product / Growth
- **What to automate:** Once Bloggo has beta testers, agent reads the `docs/marketing/bloggo-product-context.md` and generates a 5-email onboarding drip sequence for new beta users (Day 1, Day 3, Day 7, Day 14, Day 30). Each email: one feature highlight, one question to drive feedback, one low-friction CTA. Drafts land in `output/Content/beta-onboarding-[date].md` for Yoobin to review and load into a sending tool (Loops.so or Mailchimp). Turn beta signups into engaged feedback sources automatically.
- **Tool/MCP:** Claude + filesystem read/write + Loops.so API (or Mailchimp)
- **Time saved:** 8-10 hours of writing time upfront; then automated per new signup
- **Difficulty:** Medium — email copy is Claude-driven; the sending automation depends on which tool is chosen
