### 1. Content → Video Script Converter
- **Area:** Content Creation
- **What to automate:** After each morning's carousel HTML is generated, an agent reads the slide copy and auto-generates a TikTok/Reel voiceover script — with per-slide timing notes, hook sentence, b-roll suggestions, and caption. Output saved as `output/Scripts/[date]-carousel-scripts.md`. Turns a finished carousel into a shoot-ready video brief in under 60 seconds.
- **Tool/MCP:** Claude (file read → script generation) + filesystem write
- **Time saved:** ~2.5 hours/week — removes the friction between "carousel ready" and "video recorded"
- **Difficulty:** Easy — the carousel HTML already contains all slide text; Claude just needs to reformat it for video pacing

### 2. App Store Review Monitor Agent
- **Area:** Research / Competitive Intelligence
- **What to automate:** Weekly agent searches App Store reviews for Polarsteps, Day One, Journey, and Marco Polo. Extracts 1-star and 2-star complaints, clusters by theme (crashes, privacy, export, sharing, cost), and outputs a ranked "Competitor Weakness Report" to `output/Research/competitor-gaps-[date].md`. Each weakness becomes a Bloggo content angle or roadmap input.
- **Tool/MCP:** WebSearch + Claude clustering + filesystem write
- **Time saved:** ~3 hours/week of manual research. Compounds: each week's report informs the next week's copy
- **Difficulty:** Medium — scraping App Store reviews requires WebSearch workaround or third-party API; Claude clustering is easy

### 3. Beta Feedback → Notion + Content Pipeline
- **Area:** Product / Content
- **What to automate:** When a beta tester submits feedback (via Typeform, email, or direct message), an agent reads the raw input, tags it (bug / feature request / praise / question), summarizes it in one sentence, routes it to Notion (Bloggo Content Engine for feature ideas, YOOBIN Content Engine if quotable as founder content), and flags anything that could become a carousel hook.
- **Tool/MCP:** Claude + Notion MCP + email/Typeform webhook trigger
- **Time saved:** ~2 hours/week — zero manual triage of beta feedback; quotable moments surface automatically as content
- **Difficulty:** Medium — needs webhook or email trigger; Notion MCP write access already partially configured

### 4. Weekly Founder Metrics Digest
- **Area:** Analytics / Personal Productivity
- **What to automate:** Every Sunday at 6pm, an agent pulls the week's key numbers — Instagram follower delta, Reel reach, top-performing post, email list size, beta signups — and writes a plain-English "Founder Week in Numbers" to `Magic/weekly-metrics-[date].md`. Flags: best post (and why), worst post (and why), one growth action for next week.
- **Tool/MCP:** Instagram Graph API (or manual paste) + Claude analysis + filesystem write
- **Time saved:** ~1.5 hours/week of manual analytics review; more importantly, forces a weekly retrospective that most solo founders skip
- **Difficulty:** Easy to Medium — manual paste mode works immediately; API integration makes it fully automatic

### 5. Press & Creator Outreach Agent
- **Area:** Distribution / Growth
- **What to automate:** Weekly agent scans tech/travel journalist bylines and indie creator newsletters (Indie Hackers digest, Product Hunt newsletter, travel content creators) for articles about photo apps, travel tools, or founder journeys. Identifies 3–5 pitch opportunities per week, drafts personalized outreach with Bloggo angle, saves drafts to `output/Outreach/[date]-pitches.md` for Yoobin to review and send.
- **Tool/MCP:** WebSearch + Claude + filesystem write
- **Time saved:** ~4 hours/week — outreach is the highest-leverage growth channel that founders skip because it's time-consuming. This makes it nearly zero-effort.
- **Difficulty:** Medium — research layer is easy; personalization quality depends on prompt engineering; sending still requires human review
