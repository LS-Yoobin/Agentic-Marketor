## Agentic Flow Ideas

> Based on the Agentic-Marketor repo + Yoobin's profile as solo co-founder building Bloggo in August 2026.

### 1. Carousel → Screenshot → Post Pipeline Agent
- **Area:** Content Distribution
- **What to automate:** When HTML files are saved to `output/Carousels/[DATE]/`, Playwright auto-screenshots each `.slide` element at 360×450px, saves PNGs to `output/Carousels/[DATE]/screenshots/`, and queues them to Instagram Graph API as a carousel draft. You approve and post from your phone; the agent handles the file prep entirely.
- **Tool/MCP:** Playwright (headless Chromium, already installed) + Instagram Graph API + filesystem watch
- **Time saved:** ~2.5 hrs/week — removes every manual screenshot step from the current workflow
- **Difficulty:** Medium — Playwright screenshotting is trivial; Instagram API requires a Business Account token

### 2. Morning Briefing → Audio Briefing Agent
- **Area:** Personal Productivity
- **What to automate:** After each `Magic/briefing-[DATE].md` is generated, a second agent converts the key sections (News, Content Ideas, Stock Snapshot) to an 8–10 minute audio summary using Claude TTS API, saves as `Magic/briefing-[DATE].mp3`, and auto-plays via AirPlay to your kitchen speaker at 6:15am. Read the briefing while making coffee, not while sitting at a desk.
- **Tool/MCP:** Claude TTS API + AirPlay/Shortcuts automation (iOS Shortcut triggered via cron)
- **Time saved:** 20 min/day of screen time converted to ambient audio — compound effect over a week
- **Difficulty:** Easy — Claude TTS is available; iOS Shortcut can play local audio on demand

### 3. Beta User Weekly Pulse Agent
- **Area:** Bloggo Product / Customer Feedback
- **What to automate:** Every Sunday at 8pm, agent sends a 3-question SMS check-in to beta users via Twilio: "What did you use Bloggo for this week?", "What frustrated you?", "What would make you tell a friend?" Responses are collected, analyzed by Claude, and delivered as a `User Signal Report` in `output/Research/` by Monday 5am — in time to inform the morning briefing.
- **Tool/MCP:** Twilio SMS API + Claude API + filesystem write
- **Time saved:** 3–4 hrs/week post-launch — replaces ad hoc feedback chasing with structured signal
- **Difficulty:** Medium — Twilio is well-documented; response parsing needs a Claude prompt

### 4. Competitor App Monitor Agent
- **Area:** Research / Competitive Intelligence
- **What to automate:** Every Monday, agent scrapes App Store search results for "travel journal", "travel blog app", "trip journal", captures new apps and rating changes for existing competitors (Day One, Polarsteps, Journey, Memoir), extracts user complaint themes from recent 1–3 star reviews, and outputs a 1-page competitive brief to `output/Research/competitor-pulse-[DATE].md`. Catches competitor feature launches before they're announced on Twitter.
- **Tool/MCP:** WebSearch + App Store scraping via Playwright + Claude analysis + filesystem write
- **Time saved:** 2 hrs/week — currently done manually and inconsistently
- **Difficulty:** Easy–Medium — WebSearch already wired; needs App Store URL parsing

### 5. Idea Inbox → Notion Auto-Capture Agent
- **Area:** Personal Productivity / Content Operations
- **What to automate:** Yoobin writes raw ideas into `docs/marketing/Idea Inbox.md` any time. A file-watch agent triggers on every save, extracts new bullet points added since the last run, classifies each (Yoobin vs. Bloggo, format, pillar, priority), and pushes them directly to the correct Notion database — no copy-paste, no manual entry, no ideas lost between the inbox and Notion.
- **Tool/MCP:** Filesystem watch + Notion MCP + Claude classification
- **Time saved:** ~1.5 hrs/week — ideas currently stall between capture and Notion, reducing their actual use
- **Difficulty:** Easy — Notion MCP already partially wired; classification prompt is straightforward
