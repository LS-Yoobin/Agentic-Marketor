## Agentic Flow Ideas

> Based on repo structure and Yoobin's profile as a solo co-founder building Bloggo + a personal brand. Five ideas distinct from the May 14 briefing set (which covered: Travel Expense Tracker, GitHub Issue → Content Pipeline, Founder Health Check, Competitive Intelligence Monitor, Social Caption Scheduler).

### 1. Content Repurposing Agent
- **Area:** Content / Distribution
- **What to automate:** After each morning's carousels are generated, an agent extracts the text copy from each slide, then generates: 5 tweet/X thread variations, 1 LinkedIn post version, and 1 newsletter paragraph — all in Yoobin's voice. Outputs to `output/Repurposed/[date]/`. One carousel → 7 pieces of content without lifting a finger.
- **Tool/MCP:** Claude + filesystem read/write (parse HTML for slide text) + optional Buffer API for scheduling
- **Time saved:** ~3 hours/week of manual reformatting
- **Difficulty:** Easy — HTML parsing is straightforward; Claude repurposing prompt is low-lift once built

### 2. App Store Review Language Library
- **Area:** Product Development / Copywriting
- **What to automate:** Weekly agent pulls top reviews for Polarsteps, Day One, and Journey (via WebSearch or a scraping tool). Clusters 1–3 star complaints by theme and adds the actual phrases users use (their words, not marketing words) to a living `docs/marketing/customer-language-library.md`. Feeds Bloggo's copywriting with real user vocabulary — no focus groups needed.
- **Tool/MCP:** Claude + WebSearch + filesystem write
- **Time saved:** ~2 hours/week of manual research; produces copy that converts because it mirrors how users actually speak
- **Difficulty:** Medium — App Store scraping requires workaround (WebSearch-based approach) or third-party API

### 3. Monthly Founder Burn Rate Calculator
- **Area:** Finance / Founder Operations
- **What to automate:** Once a month, agent reads a bank export CSV dropped into a watched folder (`Magic/finance-input.csv`), categorizes expenses into buckets (Product Dev / Marketing / Tools / Personal), calculates monthly burn rate + estimated runway, and writes a "Founder Finance Check" markdown to `Magic/finance-[YYYY-MM].md`. Sunday morning habit: drop the CSV, get the summary.
- **Tool/MCP:** Claude + filesystem read/write (CSV → markdown)
- **Time saved:** ~1.5 hours/month; prevents blind spots on runway
- **Difficulty:** Easy — CSV parsing + Claude categorization + markdown output; no API integrations needed

### 4. "Ideas While Traveling" Capture Agent
- **Area:** Personal Productivity / Content
- **What to automate:** iOS Shortcut (speak or type a quick idea) → webhook → Claude API → tagged and expanded into a one-paragraph brief → routed to the right Notion database (Product / Content / Life). No more lost shower thoughts, airport insights, or mid-hike epiphanies that evaporate before you land. Ideas get captured and contextualized in real-time.
- **Tool/MCP:** iOS Shortcuts → webhook → Claude API → Notion MCP
- **Time saved:** Hard to quantify in hours — but captures high-value founder insights that currently vanish; one good saved idea can be worth weeks of execution
- **Difficulty:** Medium — requires iOS Shortcut setup + webhook endpoint + Claude API call + Notion MCP write; all achievable with existing stack

### 5. Beta Waitlist Nurturer Agent
- **Area:** Growth / Social Media
- **What to automate:** Weekly agent reads beta waitlist count from a Notion DB (or simple CSV), writes a short "status update" email in Yoobin's voice (personal, specific, not corporate), and queues it to the waitlist via a send tool (Loops, Resend, or SendGrid). Keeps waitlist warm with genuine founder updates — not automated blasts. Waitlist members feel seen without Yoobin writing each one manually.
- **Tool/MCP:** Claude + Notion MCP (read waitlist DB) + Resend or Loops API
- **Time saved:** ~2 hours/week of manual email drafting at scale
- **Difficulty:** Medium — depends on email API credentials; Claude drafting layer is easy; Notion read is already in scope
