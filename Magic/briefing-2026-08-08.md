## Agentic Flow Ideas

> Based on repo structure and Yoobin's profile as a solo co-founder building Bloggo + a personal brand. Distinct from ideas in previous briefings.

### 1. Instagram Carousel → Screenshot → Scheduled Post Pipeline
- **Area:** Content Distribution
- **What to automate:** After carousel HTML files are generated each morning, a Playwright agent screenshots each slide at 360×450px, stitches them into a 4-image batch, generates a caption (Claude), and queues the full carousel post via Buffer or Later API. From HTML to scheduled Instagram post with zero manual steps.
- **Tool/MCP:** Playwright (pre-installed at `/opt/pw-browsers/chromium`) + Buffer or Later API + Claude caption generation + filesystem
- **Time saved:** ~3–4 hours/week — the biggest single-step automation for content distribution
- **Difficulty:** Medium — Playwright is already available; needs Buffer/Later API key and one scheduling script

### 2. Daily Trend Radar → Idea Inbox Auto-Fill
- **Area:** Content / Research
- **What to automate:** A lightweight 4:45 AM agent (runs before carousel generator) searches TikTok/Instagram trends for founder + travel + app keywords, extracts 3–5 viral hook structures matching Yoobin's content pillars, and appends them to `docs/Marketing/Idea Inbox.md`. Every morning the Inbox is pre-filled with fresh signal before the carousel generator reads it.
- **Tool/MCP:** Claude + WebSearch + filesystem write
- **Time saved:** ~45 minutes/day of trend research, compounding into a constantly fresh idea backlog
- **Difficulty:** Easy — WebSearch + Claude + filesystem write already in place; just needs a cron hook at 4:45 AM

### 3. Beta Feedback Loop Agent
- **Area:** Product / Customer
- **What to automate:** Once beta testers are active, agent monitors a shared Notion DB (or email inbox tagged "beta feedback"). On each new entry: categorizes it (bug / feature / UX / delight), assigns severity 1–3, and appends to a prioritized backlog in Notion. Every Sunday, generates a "Beta Pulse" summary — top 3 insights + top 1 quick win — as a Notion page. Closes the feedback loop automatically.
- **Tool/MCP:** Notion MCP + Claude + Gmail MCP (if email-based feedback)
- **Time saved:** ~2–3 hours/week of manual feedback triage
- **Difficulty:** Medium — needs Notion MCP write access + feedback schema defined upfront

### 4. App Store Revenue Daily Pulse
- **Area:** Finance / Revenue
- **What to automate:** After Bloggo launches, agent reads the daily App Store Connect revenue CSV (downloaded or via API), logs to a Notion database, and generates a weekly "Revenue Pulse" note with: growth % WoW, conversion rate from trial → paid, and cohort breakdown by install week. Sends a PushNotification if daily revenue drops >20% vs. 7-day average.
- **Tool/MCP:** App Store Connect API or CSV parser + Notion MCP + Claude analysis + PushNotification
- **Time saved:** ~2 hours/week of manual financial tracking; more importantly, surfaces anomalies before they compound
- **Difficulty:** Medium-Hard — App Store Connect API requires key provisioning; Claude analysis layer is straightforward once data is piped in

### 5. Competitive App Review Intelligence Agent
- **Area:** Research / Product Strategy
- **What to automate:** Weekly Saturday agent (ties to today's privacy angle) scrapes 1–3 star App Store reviews for Bloggo competitors: Polarsteps, Day One, Google Photos, Apple Memories. Extracts recurring complaints, clusters by theme using Claude, and ranks them by frequency. Outputs a "Competitor Weakness Report" to `output/Research/competitor-gaps-[date].md`. Directly informs next week's carousel hooks and product roadmap.
- **Tool/MCP:** WebSearch (App Store review URLs) + Claude analysis + filesystem write
- **Time saved:** ~3 hours/week of manual competitive research
- **Difficulty:** Medium — App Store reviews are publicly accessible; scraping at scale requires a workaround but manual paste + Claude analysis is immediately usable
