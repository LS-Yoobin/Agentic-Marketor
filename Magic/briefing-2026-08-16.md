## Agentic Flow Ideas

> 5 new ideas for Aug 16 — distinct from the May 14 set (Travel Expense Tracker, GitHub→Inbox, Health Check, Competitive Intel Monitor, Caption Scheduler already covered).

### 1. App Store Review Sentiment Monitor
- **Area:** Product / User Feedback
- **What to automate:** Daily agent checks Bloggo's App Store reviews (via a third-party API like AppFollow or manual scrape), extracts all new 1–3 star reviews, clusters them by theme (UI bug, missing feature, confusion, crash), and writes a "What Users Hated Today" summary to `output/Research/app-store-feedback-[date].md`. Also flags any 5-star reviews with quotable copy for marketing use.
- **Tool/MCP:** Claude + AppFollow API (or manual paste → Claude analysis) + filesystem write
- **Time saved:** ~2 hours/week of manual review triage
- **Difficulty:** Easy — if using manual paste input; Medium — if wiring to AppFollow API

### 2. Travel Content Repurposing Agent
- **Area:** Content Distribution
- **What to automate:** After each carousel is generated (e.g., today's 4 carousels), agent reads each carousel's copy and automatically adapts it into 3 formats: (1) a Twitter/X thread, (2) a LinkedIn long-form post, (3) a TikTok script with spoken word and on-screen text breakdown. Output drops to `output/Content/repurposed-[date].md`. One piece of content becomes 4× the distribution.
- **Tool/MCP:** Claude + filesystem read/write (carousel `.brief` sections as input)
- **Time saved:** ~3 hours/week of manual adaptation
- **Difficulty:** Easy — Claude prompt engineering task with structured output format

### 3. Beta User Day-1 Email Agent
- **Area:** Growth / User Retention
- **What to automate:** When a new user signs up for the Bloggo beta (webhook from backend), an agent receives the user's email and sign-up timestamp, then sends a personalized Day 1, Day 3, and Day 7 email sequence. Day 1: "Here's how to blog your first trip in 60 seconds." Day 3: "Did you find any trips? Most users find 3+ on first scan." Day 7: "Here's what other beta users created this week." No generic drip — each email references real Bloggo behavior patterns.
- **Tool/MCP:** Claude + Resend/SendGrid API + backend webhook
- **Time saved:** ~4 hours/week of manual follow-up during beta; directly impacts activation and retention metrics
- **Difficulty:** Medium — needs backend webhook + email API credentials; Claude personalization layer is straightforward

### 4. Daily Founder Metrics Digest
- **Area:** Product / Analytics
- **What to automate:** Each morning at 6 AM, an agent pulls key metrics from Bloggo's backend (new signups, blogs created, PDF exports, DAU) and writes a 5-line plain-English summary to `Magic/metrics-[date].md`. Format: "Yesterday: X new users, Y blogs created, Z exports. Week-over-week: up/down X%. Highest activity hour: 8 PM." Also flags any metric that dropped >20% from the day before as a ⚠️ alert.
- **Tool/MCP:** Claude + custom backend API call + filesystem write + cron trigger
- **Time saved:** 20 minutes/day of manual dashboard checking; more importantly, ensures no metric goes unnoticed
- **Difficulty:** Medium — needs API credentials and backend metric endpoints wired in

### 5. Voice Note → Draft Social Post Pipeline
- **Area:** Content Creation / Personal Productivity
- **What to automate:** Yoobin drops a voice note (via iPhone shortcut → transcription) into a watched folder (`Magic/voice-inbox/`). Agent picks it up, transcribes if needed, extracts the core idea, and generates 3 draft social posts: one carousel hook + outline, one Reel script, one X/LinkedIn one-liner. Output goes to `output/Content/from-voice-[date].md`. The raw thought becomes a publishable draft before Yoobin opens his laptop.
- **Tool/MCP:** Claude + Whisper API (transcription) + filesystem watch + cron trigger
- **Time saved:** ~3 hours/week of taking rough ideas to publishable drafts
- **Difficulty:** Medium — Whisper API for transcription is well-documented; the hardest part is the iPhone shortcut to drop files into the watched folder (Shortcuts app + iCloud sync)
