### 1. Social Media Performance Dashboard Agent
- **Area:** Content / Distribution
- **What to automate:** Agent pulls weekly Instagram, TikTok, and X analytics via APIs. Ranks top-performing posts by saves, shares, and profile visits. Identifies which content pillars are growing, which are flat. Outputs a 5-bullet "this week's signal" summary to Magic/ every Monday morning alongside the briefing.
- **Tool/MCP:** Instagram Graph API + TikTok Content API + Notion MCP write
- **Time saved:** ~3 hours/week spent manually reviewing stats across platforms
- **Difficulty:** Medium — API access setup is the hardest part; logic is straightforward

### 2. Beta Waitlist Nurture Agent
- **Area:** Product / Growth
- **What to automate:** When a new email joins the Bloggo beta waitlist, agent triggers a 3-email drip sequence: (1) Welcome + what to expect, (2) "How Bloggo works" explainer sent 3 days later, (3) "Your beta access is almost ready" excitement builder at day 7. No manual email writing. Agent also segments by source (IG vs. TikTok vs. referral) and personalises the opening line.
- **Tool/MCP:** Resend API (email) + Notion MCP (waitlist DB) + Claude API (personalisation)
- **Time saved:** ~4 hours/week in manual email management as waitlist scales
- **Difficulty:** Medium — needs Resend API setup and Notion waitlist schema

### 3. App Store Review Monitor Agent
- **Area:** Product / Feedback Loops
- **What to automate:** Agent checks App Store reviews daily. Categorises each review (bug report, praise, feature request, UX confusion). Flags 1-star reviews with response drafts for Yoobin to review. Sends a weekly digest: star rating trend, top 3 themes, any emerging issues. First line of support filtering without hiring a team.
- **Tool/MCP:** App Store Connect API + Claude API (sentiment + category) + Notion MCP (log)
- **Time saved:** ~2 hours/week in manual review monitoring; eliminates response lag that kills App Store rank
- **Difficulty:** Easy-Medium — App Store Connect API is well-documented

### 4. Founder Content Repurposing Agent
- **Area:** Content
- **What to automate:** Yoobin records one 5-minute voice memo or video per day. Agent transcribes it, extracts 3–5 distinct insights, formats each as: (a) a tweet thread, (b) a carousel hook, (c) an Instagram caption. Drops all 3 formats into a Notion page for review. One raw thought → 10 pieces of content. No extra work.
- **Tool/MCP:** Whisper API (transcription) + Claude API (formatting) + Notion MCP (output)
- **Time saved:** ~6 hours/week of content formatting and ideation
- **Difficulty:** Easy — mostly prompt engineering and Notion MCP writes

### 5. Weekly Finance Snapshot Agent
- **Area:** Finance / Personal
- **What to automate:** Agent reads Yoobin's transaction exports (CSV from bank/card) weekly. Categorises by: Bloggo business spend, personal, travel, tools/subscriptions. Flags any recurring charges over $50 for review. Generates a one-page weekly "burn snapshot" to Magic/finance-[date].md. Know exactly where the money goes without touching a spreadsheet.
- **Tool/MCP:** Filesystem read (CSV exports) + Claude API (categorisation) + Markdown write
- **Time saved:** ~2 hours/week in manual finance tracking
- **Difficulty:** Easy — no external APIs required; runs on local CSV files
