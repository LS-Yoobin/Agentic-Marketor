### 1. Travel Content Calendar Sync Agent
- **Area:** Content Distribution
- **What to automate:** Each morning after the daily briefing generates carousel ideas, an agent checks World Cup 2026 match schedule, major travel events, and trending travel destinations for the week. It maps today's content ideas against those moments and flags the highest-overlap combination (e.g., "World Cup round of 16 today → carousel about 'I blogged my World Cup trip with Bloggo' — best posting window: 2 hours before kickoff"). Pushes the recommendation to `Magic/post-timing-[date].md`.
- **Tool/MCP:** Claude + WebSearch (event schedule API) + filesystem write
- **Time saved:** 1.5 hours/week of manual calendar-checking and post-timing research
- **Difficulty:** Easy — WebSearch + Claude reasoning + file write; no external auth required

### 2. Beta Signup Welcome Email Drip Agent
- **Area:** Marketing / Growth
- **What to automate:** When a new beta signup appears in a watched CSV or Notion DB, an agent triggers a 3-email welcome sequence: (1) Day 0 — personal welcome from Yoobin, (2) Day 3 — product education ("here's what Bloggo actually does"), (3) Day 7 — "you haven't tried it yet" soft nudge. All emails are written in Yoobin's voice, dynamically personalized with the user's signup source (Instagram, App Store, etc.). Uses no SaaS subscription cost — just Claude + simple SMTP via a serverless function.
- **Tool/MCP:** Claude (email drafting) + Notion MCP (read signups) + SMTP/Resend API
- **Time saved:** 3+ hours/week that currently goes to manual follow-up or falls through the cracks entirely
- **Difficulty:** Medium — requires a Resend or Postmark API key and a simple trigger; Claude drafting layer is straightforward

### 3. Competitor App Update Tracker
- **Area:** Product / Research
- **What to automate:** Weekly agent checks App Store update notes for Polarsteps, Day One, Journey, and Google Photos. Extracts new features mentioned, cross-references against Bloggo's roadmap, and outputs a "Competitive Moves" summary to `output/Research/competitor-updates-[date].md`. Flags if any competitor ships something close to a Bloggo differentiator (e.g., "Day One just added on-device AI" would be a red alert).
- **Tool/MCP:** Claude + WebSearch (App Store pages) + filesystem write
- **Time saved:** 2 hours/week of manual competitor monitoring
- **Difficulty:** Easy — App Store update notes are public; WebSearch retrieves them; Claude does the comparison

### 4. Weekly Founder Metrics Digest
- **Area:** Building in Public / Content
- **What to automate:** Every Sunday, an agent compiles a plain-language "week in numbers" summary for Bloggo: beta signups this week, GitHub commits, new content posted, Instagram engagement summary (pasted in manually or via API). - **Tool/MCP:** Claude + Notion MCP (write) + filesystem read (briefing history)

### 5. App Store Review Sentiment Pulse
