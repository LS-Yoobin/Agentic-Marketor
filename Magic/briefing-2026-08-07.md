### 1. App Store Review Monitor
- **Area:** Customer Intelligence / Product
- **What to automate:** Weekly agent scrapes App Store reviews for Bloggo and top competitors (Polarsteps, Day One, Journey). Clusters by sentiment theme. Flags all new 1-star and 2-star reviews. Writes a "Voice of Customer" brief to `output/Research/reviews-[date].md`. Sends a daily digest of any new Bloggo review via push notification.
- **Tool/MCP:** WebSearch (App Store scraper endpoint) + Claude sentiment clustering + filesystem write
- **Time saved:** 4 hours/week — eliminates manual review monitoring entirely
- **Difficulty:** Medium — App Store scraping requires a third-party API (AppFollow or AppBot) or manual paste; Claude analysis layer is straightforward

### 2. Content Repurposing Engine
- **Area:** Content Distribution
- **What to automate:** After each morning's carousels are saved to `output/Carousels/[date]/`, agent reads the HTML, extracts all slide copy, and auto-generates: (a) a LinkedIn long-form post version, (b) an X/Twitter 5-tweet thread, (c) a TikTok script with spoken VO and B-roll cues. Saves each to `output/Repurposed/[date]/`. One idea → 4 formats in one automated step.
- **Tool/MCP:** Claude + filesystem read/write + scheduled trigger post-carousel generation
- **Time saved:** 5–6 hours/week — the single highest-leverage content multiplication task
- **Difficulty:** Easy — Claude already reads HTML; just needs an extraction prompt and format templates

### 3. Founder Evening Journal Agent
- **Area:** Mental Health / Clarity / Patterns
- **What to automate:** Each evening at 9 PM, agent writes 3 reflection prompts to a watched file. Yoobin drops 2–3 lines of answers. Agent logs structured entry to a Notion journal DB (`Founder Journal` database). Monthly agent reads all entries and writes a "Month in Review" summary: top wins, top blocks, energy patterns, and one insight for the next month.
- **Tool/MCP:** Claude + Notion MCP + scheduled cron trigger
- **Time saved:** 20 min/day of friction replaced by passive capture; monthly review takes 0 hours instead of 2
- **Difficulty:** Easy — Notion MCP already in scope; needs a structured input file and a monthly synthesis prompt

### 4. Beta Feedback → Product Pipeline Agent
- **Area:** Product Development / Customer Feedback
- **What to automate:** When beta testers email `linkedspacesllc@gmail.com` with feedback, agent (triggered by Gmail webhook or daily email scan) reads the email, extracts the core request or bug, creates a GitHub issue with labels (bug/feature/UX/copy), and appends a one-line summary to `docs/marketing/Idea Inbox.md` as a potential content angle. Closes the feedback → product → content loop automatically.
- **Tool/MCP:** Gmail API + Claude extraction + GitHub MCP (issue create) + filesystem write
- **Time saved:** 2–3 hours/week of inbox triage + manual issue creation
- **Difficulty:** Medium — Gmail API requires OAuth setup; GitHub MCP is already available; Claude extraction is straightforward

### 5. Weekly Startup Metrics Brief
- **Area:** Finance / Business Intelligence
- **What to automate:** Connects to App Store Connect API (or reads a manually dropped CSV) to pull: weekly downloads, trial-to-paid conversion %, and estimated MRR. Writes a "Weekly Startup Metrics" brief to `Magic/metrics-[date].md`. Tracks week-over-week deltas. Flags any metric that drops >10% with a ⚠️. Designed to replace ad-hoc dashboard checking with a push-format weekly digest.
- **Tool/MCP:** App Store Connect API + Claude analysis + filesystem write + scheduled cron
- **Time saved:** 2 hours/week of manual dashboard checking
- **Difficulty:** Hard — App Store Connect API requires API key setup and token auth; analysis layer is easy once connected
