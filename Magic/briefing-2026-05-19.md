- **What to automate:** After every carousel HTML is generated, this agent reads the `.brief` box from the HTML file, extracts the caption CTA + hook type, then (a) generates 3 caption variations at different lengths (50w, 150w, 280w), (b) writes a scheduling entry to `output/Content/post-queue.csv` with suggested posting time + platform, and (c) sends a webhook ping to a no-code scheduler (n8n or Make.com) for approval. One tap to approve, one tap to post.
- **Area:** Content Distribution
- **Tool / MCP:** Claude API (caption gen) + filesystem + n8n/Make.com webhook
- **Time saved:** ~1.5 hours/week of manual caption writing and scheduling
- **Difficulty:** Medium — n8n webhook setup is the main lift

- **Tool / MCP:** Filesystem watch + Claude API + Idea Inbox file write
- **Time saved:** ~1.5 hours/week (capturing insights that currently evaporate in transit)
- **Difficulty:** Easy — a simple Claude prompt + watched file loop; implement this week

### 4. Beta Feedback Triage Agent
- **Area:** Product / Customer Feedback Loops
- **What to automate:** When TestFlight feedback arrives via email or App Store Connect, agent parses it, categorizes each item (bug / UX issue / missing feature / praise), tags severity (critical / minor / nice-to-have), and appends to `output/Research/beta-feedback-log.md`. - **Time saved:** ~1.5 hours/week post-launch; prevents feedback from getting lost in email
