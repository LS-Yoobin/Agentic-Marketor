3. **Comments are becoming content.** Posts built to trigger discussion (strong opinion, contrarian take, open-ended question) travel further than posts built to inform. Design for swipe AND for reply.

4. **Longer narrative formats returning through carousels and newsletters.** Short Reels still dominate reach, but carousels and newsletters are capturing the "save and return" behavior that feeds actual conversion. The carousel is not dead — it's the depth layer under the Reel.

5. **Post 4–5× per week; track saves and shares above likes.** In 2026, Instagram's algorithm weights completion rate (Reels) and saves/shares (carousels) over raw likes. Build for those signals.

6. **TikTok carousel format using audio sync is trending.** Photo carousel posts synced to trending audio are gaining FYP distribution. This format is low-effort to produce and performant for product education.

7. **Female founders and indie hackers are dominant content archetypes.** Content featuring authentic founder stories (especially early-stage, pre-scale) earns the highest trust score from audiences in September 2026. Yoobin's personal brand is positioned exactly right.

8. **iOS on-device AI is a growing consumer trend signal.** As App Store tightens data transparency rules, on-device AI is becoming a credibility signal, not just a privacy feature. Bloggo's message has never been more timely.

## Agentic Flow Ideas

> 5 concrete automation ideas for Yoobin — across content, productivity, product, and finance areas. Based on current repo structure.

### 1. Content Calendar Auto-Filler Agent
- **Area:** Content Creation
- **What to automate:** Each Sunday evening, agent reads the Idea Inbox, briefing archive, and last 7 days of carousels. Generates a full content calendar for the coming week — assigned to Yoobin or Bloggo account, format selected, slot filled. Saves to `output/Content/content-calendar-[YYYY-MM-DD].md`. No decisions required Monday morning.
- **Tool/MCP:** This workflow + Claude + filesystem write + Notion MCP (writes to Bloggo Content Engine)
- **Time saved:** ~2.5 hours/week (calendar planning + brief creation removed entirely)
- **Difficulty:** Easy — already have all source docs; just needs a Sunday 6 PM cron

### 2. Beta User Feedback Loop Aggregator
- **Area:** Product Development
- **What to automate:** When Yoobin receives TestFlight feedback or DMs about Bloggo, agent ingests the text (pasted or forwarded to a Notion inbox), clusters it by feature area, tags severity (bug / friction / delight), and creates a weekly digest. Every Monday, a "What Users Said" summary lands in Notion automatically.
- **Tool/MCP:** Claude API (Claude Haiku for classification speed) + Notion MCP + webhook trigger from a simple form or shared email
- **Time saved:** ~3 hours/week during active beta period — turns 50 raw messages into 5 actionable bullets
- **Difficulty:** Medium — needs an ingestion endpoint (email forward or Notion form) and Claude classifier

### 3. Daily Expense Snapshot Agent
- **Area:** Finance / Founder Spending
- **What to automate:** Each night at 11 PM, agent reads Yoobin's bank transaction CSV export (placed in a watch folder) and categorizes each transaction (Software, Travel, Marketing, Personal) using Claude Vision + text classification. Generates a weekly founder expense report saved to `output/Finance/`. Flags anything over $200 as "review me."
- **Tool/MCP:** Claude API (Vision for receipts) + filesystem + Notion MCP
- **Time saved:** ~1.5 hours/week on bookkeeping; prevents end-of-quarter surprises
- **Difficulty:** Medium — needs a CSV watch pattern or bank export hook; classification prompt needs one-time tuning

### 4. App Store Review Monitor + Response Drafter
- **Area:** Product / Customer Feedback
- **What to automate:** Daily agent checks the App Store Connect API for new reviews of Bloggo. For any new review (positive or negative), it drafts a response, saves the draft to Notion, and flags low-star reviews for Yoobin's approval before posting. Never posts without approval — human in the loop on all public responses.
- **Tool/MCP:** App Store Connect API (REST) + Claude API (response drafting) + Notion MCP
- **Time saved:** ~1 hour/week — zero missed reviews, zero cold-drafting from scratch
- **Difficulty:** Medium — App Store Connect API requires App Store Connect credentials and JWT auth; well-documented

### 5. Health + Habits Check-In Tracker
- **Area:** Health / Habits
- **What to automate:** Each morning at 6 AM, agent sends Yoobin a 3-question check-in (sleep hours, workout done?, energy level 1–5) via a simple local endpoint or mobile shortcut. Claude logs the answers to a weekly habit CSV and generates a Friday "body stats" note. Flags any week with 3+ consecutive low-energy days as a "recovery week" signal.
- **Tool/MCP:** Webhook (simple form or iOS Shortcut) + Claude API + filesystem CSV + Notion MCP
- **Time saved:** ~30 min/week tracking manually; ~much higher value in preventing burnout during high-output sprints
- **Difficulty:** Easy — form can be a one-URL iOS Shortcut that posts JSON; Claude writes the summary
