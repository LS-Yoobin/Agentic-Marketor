## Agentic Flow Ideas

> Based on repo structure and Yoobin's workflow as a solo co-founder building Bloggo + personal brand. Five ideas distinct from previous briefing sets.

### 1. Screenshot → Scheduled Post Pipeline
- **Area:** Content Distribution
- **What to automate:** After the morning carousel run generates HTML files, a headless browser (Puppeteer via Node.js) auto-screenshots each slide at 360×450px, compiles them into a folder, then queues to Buffer or Later API with an AI-generated caption and hashtag set. Zero manual copy-paste from HTML to scheduler.
- **Tool/MCP:** Node.js + Puppeteer + Buffer API + Claude for captions
- **Time saved:** ~3 hours/week (manual screenshot-to-scheduler loop eliminated entirely)
- **Difficulty:** Medium — Puppeteer setup is well-documented; Buffer API is straightforward; main challenge is auth setup once

### 2. Weekly Beta Feedback Digest
- **Area:** Product / Customer Feedback
- **What to automate:** Every Sunday, agent scans TestFlight feedback and any beta Discord/Slack messages, clusters by theme using Claude, writes a ranked "Top 5 User Complaints + Top 5 Requested Features" digest to `output/Research/feedback-[date].md`. First thing Yoobin sees Monday morning.
- **Tool/MCP:** TestFlight (manual paste workaround) + Claude + filesystem write
- **Time saved:** ~3 hours/week of manual review parsing; ensures nothing gets missed in the beta window
- **Difficulty:** Hard — TestFlight has no public API; best workaround is manual paste into a watched file, then Claude processes it automatically

### 3. Expense Auto-Logger via Voice Note
- **Area:** Finance
- **What to automate:** Drop a 10-second voice note to a watched folder (`Magic/expenses-inbox/`) describing any expense: "Coffee $5 work." Whisper transcribes, Claude categorizes (founder expense vs personal), logs to `Magic/expenses.csv`, generates a monthly P&L summary every 1st of the month.
- **Tool/MCP:** Whisper API + Claude + filesystem scheduled write + optional Notion MCP for P&L
- **Time saved:** ~2 hours/week of receipt-tracking friction; eliminates the "I'll log it later" habit
- **Difficulty:** Medium — Whisper + Claude pipeline is straightforward; the file-watch trigger needs a one-time setup

### 4. Competitive Feature Tracker
- **Area:** Product Strategy / Research
- **What to automate:** Every Monday, agent searches for App Store update notes for Polarsteps, Day One, Journey, and Futureland. Extracts any new features released that week. Claude writes a 1-paragraph "What Competitors Shipped This Week" summary, appended to `output/Research/competitor-tracker.md`.
- **Tool/MCP:** WebSearch + Claude + filesystem write
- **Time saved:** ~2 hours/week of competitive monitoring
- **Difficulty:** Easy — WebSearch + Claude pattern already working in this repo; just needs a scheduled weekly trigger

### 5. World Cup → Bloggo Moment Alerts (time-sensitive through July 2026)
- **Area:** Content / Social Listening
- **What to automate:** Through July 2026, agent runs daily searches for top World Cup host city travel content. Extracts destination moment trends and suggests a Bloggo content angle tied to the cultural moment. Output to `Magic/content-alerts-[date].md`.
- **Tool/MCP:** WebSearch + Claude + filesystem write + scheduled daily trigger
