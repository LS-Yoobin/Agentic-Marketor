## Agentic Flow Ideas

> Fresh ideas for September 2026 — distinct from April–May briefing sets. Focus on areas Yoobin hasn't automated yet.

### 1. "Trip Photos Waiting" Weekly Digest Agent
- **Area:** Content / Product Dogfooding
- **What to automate:** Every Monday, an agent scans a designated "test camera roll" folder (or simulated data), runs the same trip detection logic Bloggo uses, and outputs a plain-English report: "You have 3 unprocessed trips this week. Oldest: 47 days old. Newest: 12 photos from last Thursday." Yoobin reads it as a Bloggo user first, founder second. Catches UX issues before real users do.
- **Tool/MCP:** Filesystem scan + Claude analysis + scheduled trigger (CronCreate)
- **Time saved:** ~1 hour/week of manual product testing; better dogfooding = better product decisions
- **Difficulty:** Easy — filesystem trigger + Claude pattern recognition; no external APIs needed

### 2. App Store Review Sentiment Agent
- **Area:** Product / Customer Feedback
- **What to automate:** When Bloggo launches, agent polls App Store review scraper daily (AppFollow API or Appbot API). Clusters reviews by sentiment + theme. Flags any 1-2 star reviews with a specific bug pattern → creates a draft GitHub issue + content idea in `docs/marketing/Idea Inbox.md` simultaneously. Every complaint becomes a product fix AND a content angle.
- **Tool/MCP:** AppFollow/Appbot API + GitHub MCP + filesystem write + Claude
- **Time saved:** ~3 hours/week post-launch; zero-latency response to real user pain
- **Difficulty:** Medium — requires AppFollow API key after App Store launch; Claude classification layer is straightforward

### 3. Founder Daily Intention Agent (30-second journal)
- **Area:** Personal Productivity / Habits
- **What to automate:** Each morning at 6AM, agent drops a 3-line daily intention template into `Magic/intention-[date].md`: "Today's #1 goal:", "What I'm avoiding:", "Energy check (1-5):". Yoobin fills it in under 30 seconds. At 5PM, same agent appends "Done?", "What shifted?", "Tomorrow's carry-forward:". Weekly summary auto-generated every Sunday evening with pattern analysis (are the #1 goals actually getting done?).
- **Tool/MCP:** Scheduled trigger (CronCreate) + filesystem write + Claude weekly analysis
- **Time saved:** Replaces 20-min journaling friction with 30-second structured capture; weekly insights surface patterns without manual review
- **Difficulty:** Easy — pure filesystem + scheduling; zero external API dependencies

### 4. Beta User Waitlist Nurture Agent
- **Area:** Growth / Distribution
- **What to automate:** When Yoobin collects beta signups (from bio link), agent reads the waitlist CSV weekly, segments by signup date (cohort 1 = day 0-7, cohort 2 = 8-30, etc.), and drafts personalized nurture email copy for each cohort with the correct urgency level. Early signups get "you're almost in" copy; newer ones get "here's what Bloggo does" education copy. Yoobin reviews and sends via email tool.
- **Tool/MCP:** CSV/Google Sheets connector + Claude + email draft output to `output/Emails/[date].md`
- **Time saved:** ~2 hours/week of manual email writing; maintains launch momentum between now and V1 release
- **Difficulty:** Easy-Medium — depends on signup form (Typeform, Tally, etc.) and whether a Sheets connector is available

### 5. Content Performance Feedback Loop Agent
- **Area:** Content / Distribution
- **What to automate:** Once Bloggo or Yoobin's Instagram is active, agent reads weekly reach/save/share data (from Creator Studio export or Buffer analytics), compares against previous week's carousels, identifies which hook types earned the most saves vs. most reach. Writes a 5-bullet "what worked this week" report to `Magic/content-performance-[date].md` and auto-updates the Idea Inbox to weight toward proven hook types.
- **Tool/MCP:** Buffer API or manual CSV export + Claude analysis + filesystem write
- **Time saved:** ~2 hours/week of manual analytics review; closes the feedback loop between content creation and content strategy
- **Difficulty:** Medium — requires Buffer/Later API or manual export step; Claude analysis layer is easy
