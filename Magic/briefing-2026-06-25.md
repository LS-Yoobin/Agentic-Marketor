## Agentic Flow Ideas

> 5 new automation ideas for June 25 — distinct from the April/May briefing set. Focused on gaps in Yoobin's current workflow.

### 1. App Store Review Monitor
- **Area:** Product / Research
- **What to automate:** Once Bloggo is live, agent auto-monitors App Store reviews weekly using a Playwright scraper or review API (AppFollow, Appbot). Extracts all 1-star and 2-star reviews, clusters by theme (UI, AI quality, speed, crashes), ranks by frequency, and writes a "Voice of Customer" report to `output/Research/app-store-voice-[date].md`. Optionally also monitors Polarsteps, Day One, and Journi for competitor weakness signals.
- **Tool/MCP:** Playwright + Claude (clustering) + filesystem write
- **Time saved:** 4 hours/week of manual review reading
- **Difficulty:** Medium — scraping is the hard part; Claude analysis is easy once data exists

### 2. Travel Deal Alert Agent
- **Area:** Personal / Travel Planning
- **What to automate:** Monitors flight prices and hotel deals for 3–5 target destinations Yoobin adds to a watchlist file (`Magic/travel-watchlist.txt`). Runs daily. When a price drops >30% vs. baseline, sends an email alert with the deal details and a Bloggo caption draft for the trip ("If you go, here's how you'd blog it"). Tool bridges product discovery and personal travel planning.
- **Tool/MCP:** Google Flights API or Kayak scraper + Claude + email MCP
- **Time saved:** 2 hours/week of manual checking; surfaces deals that would otherwise be missed
- **Difficulty:** Easy — watchlist file is the input; alert email is the output

### 3. Beta User Onboarding Email Sequence
- **Area:** Product / Growth
- **What to automate:** When a new Bloggo beta user signs up (webhook from auth backend), agent generates a personalized 3-email onboarding sequence (Day 0 welcome, Day 3 "have you tried this?", Day 7 feedback ask). Pulls from a template library, personalizes with user's first name and platform (how they heard about Bloggo), and queues via email API. Each email written in Bloggo brand voice automatically.
- **Tool/MCP:** Webhook trigger + Claude + SendGrid or Resend API + Notion MCP (pull template)
- **Time saved:** 5 hours/week at launch scale when user volume grows; eliminates the "I meant to follow up" problem
- **Difficulty:** Medium — webhook + Claude prompt is straightforward; email API setup takes an hour

### 4. Weekly Content Performance Report
- **Area:** Content / Analytics
- **What to automate:** Every Monday at 7AM, agent pulls engagement metrics from the last 7 days of Instagram and TikTok posts (reach, saves, comments, shares via Meta Graph API + TikTok API). Identifies top 3 performing posts. Extracts the common pattern (hook type, topic, format, word count). Writes a "What's working this week" brief to `output/Content/content-performance-[date].md` and appends to Notion. Gives Yoobin a weekly signal without manually checking dashboards.
- **Tool/MCP:** Meta Graph API + TikTok API + Claude + Notion MCP + filesystem write
- **Time saved:** 3 hours/week of dashboard checking and manual synthesis
- **Difficulty:** Hard — API credentials for both platforms required; Claude analysis layer is easy once data flows

### 5. Idea-to-Brief Pipeline
- **Area:** Content Creation
- **What to automate:** When a new raw idea is added to `docs/Marketing/Idea Inbox.md` (detected via filesystem watch or git commit hook), an agent auto-expands it into a full content brief: hook (3 variations), slide outline, format recommendation, hook type classification, Notion destination, and estimated time to produce. Appends the brief to `output/Content/` and pushes the expanded version to the correct Notion Content Engine. Closes the gap between "I have an idea" and "the idea is ready to execute."
- **Tool/MCP:** Filesystem watch (git hook or Claude Code hook) + Claude + Notion MCP + filesystem write
- **Time saved:** ~2 hours per idea × however many ideas land per week. Highest leverage per-idea automation.
- **Difficulty:** Easy — the hardest part is the git hook trigger; the Claude expansion prompt is straightforward
