## Agentic Flow Ideas

> Five new automation opportunities for Yoobin as a solo founder. All distinct from the April–May briefing sets.

### 1. App Store Review Monitor
- **Area:** Customer Research / Product
- **What to automate:** Weekly agent pulls reviews from top travel app competitors (Day One, Polarsteps, Journey, Wanderlog) via AppFollow API or web scrape. Claude clusters 1–3-star reviews by theme (e.g. "can't export PDF," "no offline mode," "too complicated"), ranks pain points by frequency, and outputs a `Competitor Pain Report` to `output/Research/competitor-pain-[date].md`. Top 3 gaps auto-append to `docs/marketing/Idea Inbox.md` as content ideas.
- **Tool/MCP:** WebFetch + Claude analysis + filesystem write
- **Time saved:** ~4 hours/week of manual competitor monitoring → fully automated weekly intel
- **Difficulty:** Easy — no auth needed for App Store web scraping; Claude analysis is a straightforward prompt

### 2. Instagram Analytics → Content Direction Agent
- **Area:** Content / Growth
- **What to automate:** After a week of posting, agent pulls Instagram Basic Display API metrics (reach, saves, comments per post) into a structured CSV. Claude analyzes which hook types, formats, and topics earned the most saves (the #1 signal for Reels and Carousels in 2026). Output: a ranked "What's Working" table + auto-adjusts next week's carousel rotation by angle. Saves go into `output/Analytics/weekly-content-report-[date].md`.
- **Tool/MCP:** Instagram Graph API + Claude + filesystem write
- **Time saved:** ~2 hours/week of manual analytics review + removes guesswork from content planning
- **Difficulty:** Medium — requires Instagram Graph API credentials; Claude analysis layer is straightforward

### 3. Evening Voice-to-Draft Agent
- **Area:** Personal Productivity / Content Creation
- **What to automate:** Each evening, Yoobin drops a 2–3 minute voice note into a watched Telegram bot (thoughts on the day, wins, lessons, observations). Agent transcribes via Whisper API, structures into a building-in-public micro-post draft, and saves to `output/Content/drafts/[date]-voicenote-draft.md`. Ready to review and post in the morning. Removes the activation energy barrier of writing from scratch.
- **Tool/MCP:** Telegram Bot API + OpenAI Whisper (transcription) + Claude (structure + polish) + filesystem
- **Time saved:** 30–45 minutes/day → removes the "I need to write a post" friction entirely
- **Difficulty:** Medium — Telegram bot setup is easy; Whisper transcription is one API call; Claude structuring is a straightforward prompt

### 4. RevenueCat MRR Dashboard Agent (Post-Launch)
- **Area:** Finance / Revenue Tracking
- **What to automate:** When Bloggo launches with in-app purchases, daily agent pulls RevenueCat API → formats subscriber count, MRR, trial conversion rate, churn rate into a one-page Notion dashboard update. Compares to prior day and prior week. Flags any metric that drops >10% from 7-day average. No more manually opening RevenueCat to check numbers.
- **Tool/MCP:** RevenueCat API + Notion MCP + Claude analysis
- **Time saved:** ~1 hour/day of manual dashboard checking; more importantly, ensures no silent revenue drop goes unnoticed for 3 days
- **Difficulty:** Easy (post-launch) — RevenueCat has a clean REST API; Notion MCP already in scope; Claude just formats and flags anomalies

### 5. Beta Cohort Re-Engagement Agent
- **Area:** Product / Growth
- **What to automate:** Weekly agent reads TestFlight/beta analytics export → identifies beta users who haven't opened Bloggo in 7+ days → generates 3 personalized re-engagement message drafts per user (based on their last known action, e.g. "You imported 3 trips — did Bloggo catch the one in Bangkok?"). Yoobin reviews and sends. Turns cold beta users into active feedback contributors.
- **Tool/MCP:** TestFlight analytics export (CSV) + Claude + output draft to Notion MCP or `output/Beta/re-engagement-[date].md`
- **Time saved:** ~2 hours/week of manual follow-up → more importantly, improves beta retention metrics before public launch
- **Difficulty:** Easy — CSV analysis + Claude generation is a simple one-shot prompt; no complex integrations
