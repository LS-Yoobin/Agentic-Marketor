## Agentic Flow Ideas

> Five ideas for automating Yoobin's work and life using AI agents. Distinct from previous briefing sets.

### 1. App Store Review Intelligence Agent
- **Area:** Product / Marketing Research
- **What to automate:** Weekly agent pulls App Store reviews for Bloggo (once live) plus competitors (Polarsteps, Day One, Journey). Extracts 1- and 2-star reviews, clusters by theme using Claude, and writes a ranked "Where competitors fail this week" report to `output/Research/competitor-review-gaps-[date].md`. Also flags if Bloggo's own rating drops below 4.2 — triggers an immediate alert.
- **Tool/MCP:** Claude + App Store Connect API (for Bloggo reviews) + WebSearch (for competitor reviews) + filesystem write
- **Time saved:** 3–4 hours/week of manual research; also catches competitive weakness windows in real time
- **Difficulty:** Medium — App Store Connect API needs credentials; competitor scraping requires a reliable third-party source or manual paste workaround

### 2. Carousel-to-Thread Repurpose Agent
- **Area:** Content Distribution
- **What to automate:** After each carousel HTML file is generated in `output/Carousels/[date]/`, an agent reads the `.brief` section, extracts the slide-by-slide copy, and auto-generates an X/LinkedIn thread version of the same content. Outputs to `output/Threads/[date]-[slug].md`. Thread keeps the same logic: hook → problem reveals → insight → CTA. One content piece becomes two posts.
- **Tool/MCP:** Claude + filesystem read (carousels) + filesystem write (threads)
- **Time saved:** 2–3 hours/week; turns every carousel into a second distribution channel with zero marginal effort
- **Difficulty:** Easy — pure Claude text transformation from existing file; no external APIs needed

### 3. Founder Decision Journal Agent
- **Area:** Personal Productivity / Mental Clarity
- **What to automate:** Every Sunday, a 5-question prompt drops into `Magic/decision-log.md`. Yoobin answers in plain text. Agent reads the log weekly, surfaces patterns ("You've made 4 decisions based on user feedback and 0 based on data — consider adding a metric"), and writes a monthly "Decision Review" report. Builds a permanent log of why each choice was made — invaluable for hindsight, investor conversations, and content.
- **Tool/MCP:** Scheduled trigger + Claude analysis + filesystem read/write
- **Time saved:** Hard to quantify in hours; the value is preventing repeated mistakes and generating founder content from real decisions
- **Difficulty:** Easy — file-based; scheduled trigger already in scope for this project

### 4. Beta User Feedback Cluster Agent
- **Area:** Product / User Research
- **What to automate:** When Yoobin receives beta feedback (email, TestFlight, DMs), paste it into a watched file `Magic/beta-feedback-inbox.txt`. Agent runs nightly, reads new entries, clusters by theme (bug, UX friction, missing feature, positive signal), scores urgency, and appends a prioritized "Beta Signals" entry to `output/Research/beta-signals-[date].md`. Also flags any feedback that would make strong social content ("This person just described Bloggo perfectly — use this as a testimonial hook").
- **Tool/MCP:** Filesystem watch + Claude analysis + filesystem write
- **Time saved:** 2 hours/week during active beta; also generates marketing copy from real user language (the highest-converting copy source)
- **Difficulty:** Easy — no external API needed; works from a simple watched file

### 5. Weekly Founder KPI Dashboard Agent
- **Area:** Finance / Growth Tracking
- **What to automate:** Every Monday morning (alongside this briefing), agent reads a watched data file (`Magic/kpi-log.csv`) where Yoobin manually enters weekly metrics: beta signups, active users, content reach (IG followers, TikTok views), and any revenue (post-launch). Generates a single-page `Magic/kpi-dashboard-[date].md` with week-over-week deltas, a "green/yellow/red" signal per metric, and one concrete recommendation per red signal. Keeps founder accountable without building a full dashboard.
- **Tool/MCP:** Claude + filesystem read/write + basic arithmetic
- **Time saved:** 1–2 hours/week; more importantly, prevents "busy but not growing" blindness
- **Difficulty:** Easy — entirely file-based; Yoobin just updates a CSV row each week
