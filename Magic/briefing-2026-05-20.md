## Agentic Flow Ideas

> Based on current repo structure: `Workflows/`, `output/`, `Magic/`, `docs/marketing/`, `scripts/` · Solo founder building Bloggo while running personal brand.

### 1. **Instagram Engagement Loop Agent**
- **Area:** Social Media Distribution
- **What to automate:** After each post goes live, agent monitors Instagram comments for the first 48 hours. Detects questions, saves replies, and drafts personalized responses for Yoobin to approve in under 30 seconds. Also tracks which comment types appear most (saves the data to `output/Content/engagement-patterns.md`) so future content can pre-answer common objections.
- **Tool/MCP:** Instagram Graph API (comment polling) + Claude API (response drafting) + filesystem write
- **Time saved:** ~3 hours/week post-launch
- **Difficulty:** Medium — Instagram API requires approved token; drafting is easy once connected

### 2. **Live Trip Simulator (Eat Your Own Dog Food Agent)**
- **Area:** Product / Research
- **What to automate:** When Yoobin travels, he drops photos into a watched `input/trips/[trip-name]/` folder. Agent simulates what Bloggo does — clusters photos by time/location, generates a first-draft blog entry using Claude, saves to `output/Content/trip-[name].md`. This is both a product test AND a content piece (the output IS the content).
- **Tool/MCP:** Filesystem watch + Claude API (vision + writing) + Exif metadata parsing
- **Time saved:** ~2 hours per trip + produces content automatically
- **Difficulty:** Medium — Claude vision handles photo analysis; Exif parsing is standard Node/Python

### 3. **Idea-to-Brief Pipeline (Founder Journal Agent)**
- **Area:** Personal Productivity / Content
- **What to automate:** Yoobin drops raw daily notes into `input/journal/YYYY-MM-DD.txt` (even just bullet points: "shipped X, felt Y, learned Z"). Agent reads it each evening, extracts 2–3 content ideas with hooks and pillars, appends them to `docs/marketing/Idea Inbox.md` with a priority score, and flags any that match a current trend signal from the morning briefing.
- **Tool/MCP:** Filesystem watch + Claude API + Idea Inbox write
- **Time saved:** ~1.5 hours/week; prevents raw insights from disappearing
- **Difficulty:** Easy — this is a single Claude API call + file write

### 4. **Weekly Burn Rate Snapshot Agent**
- **Area:** Finance / Founder Ops
- **What to automate:** Every Sunday at 6pm, agent reads a watched `input/expenses.csv` (updated by Yoobin manually or via Stripe webhook post-launch), calculates weekly burn, MRR delta, and estimated runway. Outputs a 6-line plain-English summary to `Magic/finance-[date].md`. No spreadsheet, no dashboard — just the number that tells you if you have time.
- **Tool/MCP:** CSV file parser + Claude analysis + filesystem write; Stripe API post-launch
- **Time saved:** ~1 hour/week
- **Difficulty:** Easy (CSV) / Medium (Stripe API)

### 5. **ASO Keyword Tracker Agent**
- **Area:** Product / App Store Optimization
- **What to automate:** Weekly web search for the top 10 App Store keyword rankings in travel journal, travel blog, and photo story categories. Compares against Bloggo's target keywords. Flags if a competitor has moved up. Outputs a short `output/Research/aso-[date].md` with keyword gap opportunities and suggested title/subtitle tweaks for the App Store listing.
- **Tool/MCP:** WebSearch + Claude analysis + filesystem write
- **Time saved:** ~2 hours/week pre-launch; critical for App Store discoverability
- **Difficulty:** Easy — pure search + analysis loop, no API required
