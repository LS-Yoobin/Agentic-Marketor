## Agentic Flow Ideas

### 5 Concrete Automation Opportunities for Yoobin

**1. Area: Content Distribution**
- **What to automate:** After each morning's carousels are generated and saved to `output/Carousels/[date]/`, an agent reads each `.brief` section, identifies the Notion destination, grabs today's trending hashtags via WebSearch, and appends an optimized caption + 25 hashtags to each carousel's brief. Queues to Buffer/Later API automatically.
- **Tool/MCP:** Claude + WebSearch + Buffer or Later API + filesystem
- **Time saved:** ~4 hrs/week
- **Difficulty:** Medium — depends on Buffer/Later API key setup; Claude caption layer is straightforward

**2. Area: Beta User Feedback Loop**
- **What to automate:** An agent monitors a shared email inbox (or TestFlight feedback form) daily, extracts user feedback, tags it by category (UX bug / feature request / love note / confusion), summarizes the top 3 signals per week, and writes a structured "User Signal Report" to `output/Research/`. Flags anything urgent (e.g., crashes, privacy concern) for immediate review.
- **Tool/MCP:** Email MCP (Gmail API) + Claude + filesystem
- **Time saved:** ~3 hrs/week
- **Difficulty:** Medium — needs Gmail API credentials and a structured email inbox for beta feedback

**3. Area: App Store Intelligence**
- **What to automate:** Weekly agent scans App Store reviews for Bloggo's top 5 competitors (Polarsteps, Day One, Unforgettable, Journey, Google Photos). Extracts top complaints, wishlist features, and 5-star praise. Writes a "Competitor Review Digest" to `output/Research/`. Surfaces any category where Bloggo has a clear advantage users are asking for.
- **Tool/MCP:** WebSearch + Claude + filesystem (no App Store API needed — scrape public pages)
- **Time saved:** ~2 hrs/week
- **Difficulty:** Easy — pure web search + Claude synthesis

**4. Area: Personal Finance / Revenue Tracking**
- **What to automate:** Monthly agent reads App Store Connect reports (once Bloggo launches paid tier), logs installs, conversion rates, and revenue to a running `output/Finance/revenue-tracker.md`. Compares month-over-month and surfaces: top traffic sources, conversion drop points, and a single "what to fix this month" recommendation.
- **Tool/MCP:** Claude + filesystem + App Store Connect API (once revenue is live)
- **Time saved:** ~2 hrs/month + 0 hours of forgetting to check
- **Difficulty:** Hard pre-launch (no data), Easy post-launch (just read + log)

**5. Area: Content Performance Grading**
- **What to automate:** Once Instagram API access is set up, a weekly agent pulls performance data for the last 7 days of posts (reach, saves, comments, shares). For each post, it grades performance (A/B/C/F) against a baseline, surfaces the top 3 performing content patterns, and adds a "What's Working" section to next Monday's briefing. Flags any post that overperformed to repurpose.
- **Tool/MCP:** Instagram Graph API + Claude + filesystem (existing `Workflows/performance-feedback-agent.md` already sketches this)
- **Time saved:** ~3 hrs/week
- **Difficulty:** Medium — needs Instagram API credentials and a baseline dataset (needs ~4 weeks of data)
