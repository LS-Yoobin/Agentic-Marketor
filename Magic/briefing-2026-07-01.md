### 1. Content Repurposing Agent
- **Area:** Content Creation / Distribution
- **What to automate:** After each morning's carousel HTML files are generated, an agent reads the slide copy and produces three additional assets: (1) a TikTok/Reel script with a matching hook and voice-over guide, (2) a 5-tweet thread for X, and (3) a LinkedIn version adapted for a professional tone. - **Time saved:** ~3 hours/week — currently done manually per platform
- **Difficulty:** Easy — Claude already generates the carousel; adding a post-processing reformatter is straightforward

### 2. Launch Day War Room Agent
- **Area:** Product / Community
- **What to automate:** On App Store launch day (and the first 72 hours), an agent monitors App Store review scraper, Reddit/Twitter mentions, and crash log summaries every 30 minutes. It routes each signal to the right bucket: bug report (→ Jira), positive review (→ Content Ideas inbox), feature request (→ roadmap doc), sentiment summary (→ Slack/Notion). Yoobin gets a "pulse" report every 2 hours without reading anything manually.
- **Tool/MCP:** WebSearch (social mentions) + App Store review watcher + Claude (classify & route) + Notion MCP (write to buckets)
- **Time saved:** Converts 8–12 hours of frantic launch day monitoring into a clean feed — irreplaceable on launch day
- **Difficulty:** Medium — requires a few integrations, but Claude's classification layer is easy; worth building before launch

### 3. Vibe-Coded Changelog Agent
- **Area:** Building in Public / Content
- **What to automate:** Every Sunday at 9PM, agent reads the week's git commits (excluding merge commits), summarizes them in plain English, and writes two outputs: (1) a "building in public" tweet thread draft saved to `output/Content/[date]-weekly-build.md` and (2) a 5-slide carousel brief for Yoobin's personal account. Turns code history into audience-facing storytelling automatically.
- **Tool/MCP:** GitHub MCP (list commits) + Claude (summarize → reframe as story) + filesystem write
- **Time saved:** ~2 hours/week — all the raw material is already in git; just needs a translator
- **Difficulty:** Easy — GitHub MCP is already in scope; Claude summary layer is one prompt

### 4. Travel Intent Signal Monitor
- **Area:** Market Research / Product
- **What to automate:** Weekly agent searches for "travel blog app," "how to document a trip," "best travel journal app" across Reddit, TikTok comments (via search), and Product Hunt. Extracts intent signals: what people are looking for, what pain points appear repeatedly, and what solutions they've tried. Writes a weekly "Search Intent Report" to `output/Research/intent-[date].md`. Feeds directly into ASO keyword updates and content angle rotation.
- **Tool/MCP:** Claude + WebSearch + Reddit search + filesystem write
- **Time saved:** ~3 hours/week of manual keyword and forum research
- **Difficulty:** Easy — pure search + summarize loop; no complex integrations needed

### 5. App Store Review Synthesizer (Post-Launch)
- **Area:** Product / Customer Feedback
- **What to automate:** After Bloggo launches, an agent runs weekly to pull App Store reviews (scraped or via a review API), classify them by theme (onboarding friction, feature gap, privacy concern, delight moment), and output a ranked "Voice of Customer" report. The top 3 pain points go into a `roadmap-flags.md` file; the top 3 delight moments become content idea seeds appended to the Idea Inbox. Closes the customer feedback loop without any manual review reading.
- **Tool/MCP:** App Store review API or manual paste → Claude (classify + extract) + filesystem write + Notion MCP (optional)
- **Time saved:** ~4 hours/week post-launch — the most important feedback loop for a solo founder who can't talk to 1,000 users individually
- **Difficulty:** Medium — depends on review data access; Claude analysis layer is straightforward
