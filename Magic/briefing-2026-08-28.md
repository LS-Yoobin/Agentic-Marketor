## Agentic Flow Ideas

> 5 concrete ideas for Yoobin to better automate work and life using AI agents. Based on current repo structure and solo-founder profile.

### 1. Automated Beta User Feedback → Notion Triage Agent
- **Area:** Product / Customer Feedback
- **What to automate:** After any beta feedback submission (TestFlight crash report, email reply, DM screenshot pasted to a watched folder), an agent reads the feedback, extracts: sentiment (positive/negative), feature category (AI quality, UI, export, onboarding), and a quoted pain-point sentence. Auto-adds to a Notion "Beta Feedback" database with those tags. Generates a weekly "Top 3 User Complaints" summary every Sunday.
- **Tool/MCP:** Claude vision (screenshot OCR) + Notion MCP + filesystem watcher
- **Time saved:** ~3 hours/week of manual review and categorization
- **Difficulty:** Medium — Notion MCP write is the key dependency; screenshot → text extraction is Claude vision

### 2. Instagram Caption Auto-Generator on Carousel Save
- **Area:** Content Distribution
- **What to automate:** Every time a new `.html` file is saved to `output/Carousels/[date]/`, an agent triggers (via file watch), reads the carousel's `.brief` box, and writes: (a) an Instagram caption with 3 hashtag sets (niche, broad, trending), (b) a Twitter/X version under 280 chars, (c) a LinkedIn version with founder angle. Saves all 3 to a sibling `.captions.md` file. Ready to paste.
- **Tool/MCP:** Filesystem watch + Claude + WebSearch (trending hashtags)
- **Time saved:** ~45 min/day on caption writing; removes the gap between "carousel done" and "post scheduled"
- **Difficulty:** Easy — file watch trigger already possible with Claude Code hooks; Claude does caption generation

### 3. Weekly Revenue + Metrics Dashboard Agent
- **Area:** Finance / Product Analytics
- **What to automate:** Every Sunday at 6pm, agent pulls: App Store Connect downloads/installs (via App Store Connect API), Stripe webhook data if any revenue exists, and outputs a plain-language weekly metrics report to `Magic/metrics-[date].md`. Tracks: downloads, active installs, conversion rate, and any revenue events. Flags week-over-week changes above 10%.
- **Tool/MCP:** App Store Connect API (JWT auth) + Stripe API (if applicable) + Claude analysis + filesystem write
- **Time saved:** ~2 hours/week of manual dashboard-checking; removes the founder blindspot of not knowing numbers mid-week
- **Difficulty:** Hard — App Store Connect API requires JWT setup; Stripe is straightforward; Claude analysis layer is easy once data arrives

### 4. Nightly Competitive Intelligence Sweep
- **Area:** Research / Product Strategy
- **What to automate:** Every night at 11pm, agent runs 3 WebSearches: "Bloggo app competitor news [date]", "travel journal app new feature [date]", "Polarsteps OR Day One OR Polarsteps update [date]". Extracts anything new. If nothing, stays silent. If a competitor ships something relevant, appends a 2-line summary to `output/Research/competitor-log.md` and sends a push notification.
- **Tool/MCP:** WebSearch + Claude + filesystem write + PushNotification
- **Time saved:** ~2 hours/week of manual scanning; more importantly, removes the blindspot of missing a competitor launch
- **Difficulty:** Easy — WebSearch + Claude is the core stack; already available in this repo's Claude Code setup

### 5. Health & Focus Habit Loop (Founder Mode)
- **Area:** Health / Habits
- **What to automate:** Every day at 7pm, a simple 3-question log gets appended to `Magic/health-log.txt` by asking Claude to prompt-fill based on any notes in the daily briefing: (1) Deep focus blocks today (count), (2) Steps walked (manual input once), (3) Energy level end-of-day (1–5). Every Sunday, Claude analyzes the week's log and outputs a "Founder Health Score" with a flag if 3+ consecutive low-energy days occurred — early warning for burnout.
- **Tool/MCP:** Filesystem write + Claude analysis + scheduled trigger (cron)
- **Time saved:** 20 min/day of tracking friction; prevents the "I didn't notice I was burning out" scenario that kills solo founder momentum
- **Difficulty:** Easy — file append is trivial; Claude analysis on Sunday is a 200-token job
