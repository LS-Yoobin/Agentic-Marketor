## Agentic Flow Ideas

> Based on repo structure, founder profile, and current agentic workflow state.

### 1. **Live Content Performance Agent**
- **Area:** Content / Social Media Analytics
- **What to automate:** After posting a carousel or Reel, agent monitors engagement at 1h, 6h, 24h, 72h using the Instagram Graph API. It extracts saves, shares, and reach — the "viral signals" — and appends the result to `docs/marketing/Idea Inbox.md` with a note on which hook type performed best. Then uses patterns to auto-weight hook selection in the next carousel run. Currently the briefing picks hooks manually; this closes the feedback loop.
- **Tool/MCP:** Instagram Graph API + Claude analysis + filesystem write to `Idea Inbox.md`
- **Time saved:** ~2–3 hours/week of manual review and pattern recognition
- **Difficulty:** Medium — requires Instagram Graph API access + a token refresh flow

### 2. **Founder Journal → Content Pipeline (Voice-First)**
- **Area:** Content / Personal Productivity
- **What to automate:** Yoobin records a 60-second voice note (on phone or via Whisper-powered shortcut) any time something interesting happens during the build — a good conversation, a rejection, a win, a weird insight. Agent transcribes, extracts the core idea, formats into 3 hook options, and drops into `docs/marketing/Idea Inbox.md`. Today's briefing would have richer, more personal hooks if the raw material existed. Replaces the current gap where live founder insights disappear before they're content.
- **Tool/MCP:** Whisper API (or Apple Shortcuts → STT) + Claude API + filesystem
- **Time saved:** ~2 hours/week (capturing moments that currently evaporate)
- **Difficulty:** Easy-Medium — Whisper API call + Claude prompt + file append

### 3. **App Store Beta Feedback Triage Agent**
- **Area:** Product / Customer Feedback
- **What to automate:** When TestFlight beta testers submit feedback, agent ingests it daily, clusters by theme (onboarding friction, feature requests, bugs, delighters), ranks by frequency, and appends a prioritized `Beta Feedback Summary [date]` to the product roadmap or Notion. Every morning briefing would include a "top 3 beta signals" section. Closes the feedback → insight → action loop without Yoobin manually reading every report.
- **Tool/MCP:** App Store Connect API (TestFlight) + Claude NLP clustering + Notion MCP or filesystem
- **Time saved:** ~1.5 hours/week post-beta launch
- **Difficulty:** Medium — App Store Connect API auth + clustering prompt

### 4. **Weekly Finance & Burn Rate Agent**
- **Area:** Finance / Founder Ops
- **What to automate:** Every Sunday at 9pm, agent reads a watched `expenses.csv` (manual or from a linked account export), calculates: weekly spend by category, monthly burn rate, and estimated runway at current pace. Outputs a 6-line plain-English `Magic/finance-[date].md`. Includes a "red flag" trigger: if burn exceeds a threshold (e.g., $500/week), it flags the anomaly in the next morning briefing. Simple, no dashboard needed.
- **Tool/MCP:** CSV reader + Claude analysis + filesystem write
- **Time saved:** ~1 hour/week
- **Difficulty:** Easy — pure CSV parsing + Claude summarization

### 5. **ASO Keyword Monitor Agent**
- **Area:** Product / App Store Optimization
- **What to automate:** Weekly, agent searches App Store keyword rankings for 10 target keywords (e.g., "travel blog app", "travel journal iOS", "AI travel diary") using the MobileAction or AppFollow API. Compares against prior week and flags any competitor movements or ranking gains/losses. Outputs to `output/ASO/aso-[date].md`. Currently ASO is a one-time task; this makes it a living system that catches keyword opportunities in real time.
- **Tool/MCP:** MobileAction API or AppFollow API + Claude analysis + filesystem
- **Time saved:** ~1.5 hours/week (replacing manual App Store research)
- **Difficulty:** Medium — API auth + delta tracking logic
