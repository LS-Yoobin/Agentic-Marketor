## Agentic Flow Ideas

> Five new automation ideas — distinct from the May 2026 set (Travel Expense Tracker, GitHub Issue→Content, Health Check, Competitive Intelligence Monitor, Social Caption Scheduler).
> Based on September 2026 repo structure and Yoobin's solo co-founder profile.

### 1. App Store Review Daily Digest
- **Area:** Product / Customer Feedback
- **What to automate:** Each morning, agent scrapes App Store reviews for Bloggo (via app-store-scraper npm package or an API like AppFollow). It clusters new reviews into: Bug Reports, Feature Requests, Praise, and Off-Topic. Outputs a ranked digest to `output/Research/reviews-[date].md`. Bug clusters get auto-linked to a GitHub issue draft.
- **Tool/MCP:** Claude + WebSearch (App Store review endpoint) + filesystem write + GitHub MCP
- **Time saved:** ~2 hours/week manually reading and triaging reviews; zero delay between review and response
- **Difficulty:** Medium — App Store doesn't have a public reviews API; use a third-party scraper (AppFollow free tier or `app-store-scraper` npm) + Claude classifier

### 2. Weekly Content Performance Autopsy
- **Area:** Content / Analytics
- **What to automate:** Every Sunday, agent reads last week's posted content (from a tracked log in `output/Content/`), pulls engagement data via Instagram Basic Display API, and generates a "What worked / What didn't" report. Extracts the top-performing hook type, best slide count, and content pillar, and prepends learnings to `docs/Marketing/Idea Inbox.md` for the next week's generation.
- **Tool/MCP:** Claude + Instagram API (Basic Display) + filesystem write
- **Time saved:** ~3 hours/week of manual performance review
- **Difficulty:** Medium — Instagram API setup required; Claude analysis layer is easy once data is structured

### 3. Founder Personal Finance Pulse
- **Area:** Finance / Founder Wellbeing
- **What to automate:** Weekly, agent reads exported bank statement CSV (manually dropped to `Magic/finance/`), categorizes transactions (tools/subscriptions, food, travel, personal), and generates a plain-English "Founder Spend Snapshot" to `Magic/finance-[date].md`. Flags unusual charges, subscription creep, and end-of-runway estimate based on burn rate.
- **Tool/MCP:** Claude + filesystem read/write (no external API needed — Yoobin manually drops the CSV)
- **Time saved:** 1.5 hours/week manually reviewing bank statements; also surfaces subscription creep silently bleeding cash
- **Difficulty:** Easy — Claude CSV parsing + categorization prompt is reliable; no external auth required

### 4. Launch Countdown Brain
- **Area:** Product / Scheduling
- **What to automate:** Agent reads the product roadmap (`output/2026-05-27-bloggo-product-roadmap.md`), calculates days to target launch, and each morning appends 1 targeted task to `Magic/briefing-[date].md` under a "Today's Launch Prep Task" section. Tasks rotate through: TestFlight build, App Store screenshots, ASO copy review, onboarding flow test, press outreach prep. Zero manual sprint planning.
- **Tool/MCP:** Claude + filesystem read (roadmap) + CronCreate (scheduled trigger)
- **Time saved:** ~1 hour/week of sprint planning; more importantly, keeps launch prep on rails without a PM
- **Difficulty:** Easy — pure Claude + filesystem; needs launch date set in a config file once

### 5. Beta Feedback Triage Agent
- **Area:** Product / User Research
- **What to automate:** When beta users email or message feedback (forwarded to a watched inbox folder or pasted to `Magic/feedback/`), agent reads each entry, classifies it as Bug / Feature Request / UX Confusion / Praise, extracts the affected feature, and writes a structured Notion ticket draft to `output/beta-tickets-[date].md`. High-severity bugs get a GitHub issue opened automatically via GitHub MCP.
- **Tool/MCP:** Claude + filesystem watch (`Magic/feedback/`) + GitHub MCP + Notion MCP
- **Time saved:** ~4 hours/week as beta scales; prevents feedback from getting lost in DMs
- **Difficulty:** Medium — inbox watch setup is the hardest part; Claude classification + GitHub MCP write is straightforward
