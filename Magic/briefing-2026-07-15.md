## Agentic Flow Ideas

> Five new ideas for Yoobin's automation stack — distinct from previous briefings. Focused on areas not yet covered: World Cup / summer travel timing, content distribution, financial intelligence, and feedback loops.

### 1. Travel Story Recapper Agent (Summer Window Trigger)
- **Area:** Content / Marketing
- **What to automate:** During the World Cup summer window, agent monitors trending travel destinations in the news (e.g. host cities: Dallas, LA, Miami, NYC) and auto-generates a "travel memory" carousel idea for each trending city. Agent checks your camera roll index (a local JSON of photo metadata) against trending destinations and flags: "You have 47 photos from Miami — this is trending. Generate a carousel?" Requires one approval tap.
- **Tool/MCP:** WebSearch (trending cities) + filesystem (camera roll index JSON) + Claude (carousel idea generation)
- **Time saved:** 2–3 hours/week during peak travel content windows
- **Difficulty:** Medium — needs a camera roll metadata export step (iOS Shortcuts can do this)

### 2. Beta Waitlist Sentiment Monitor
- **Area:** Product / Customer Feedback
- **What to automate:** Agent scans the beta waitlist email inbox (via Gmail MCP or email forwarding to a watched file) for replies, questions, and feedback. Clusters by theme (feature request, confusion, excitement), ranks by frequency, and writes a weekly "Beta Pulse" report to `output/Research/beta-pulse-[date].md`. Surfaces the top 3 action items automatically.
- **Tool/MCP:** Gmail MCP (or Zapier webhook → file) + Claude analysis + filesystem write
- **Time saved:** ~2.5 hours/week of manual inbox monitoring
- **Difficulty:** Easy — Claude analysis layer is simple once emails are accessible

### 3. Weekly Revenue Intelligence Digest
- **Area:** Finance / Founder Intelligence
- **What to automate:** Every Monday, agent pulls public revenue signals for travel and journaling app competitors (App Store rankings, review velocity, category position) from ASO World or similar, compares against prior week, and writes a "Competitive Revenue Signal" summary to `output/Research/revenue-intel-[date].md`. Not real financial data, but ranking-based proxy signals.
- **Tool/MCP:** WebSearch (App Store rankings) + Claude synthesis + filesystem write
- **Time saved:** ~3 hours/week of manual competitive monitoring
- **Difficulty:** Medium — requires consistent data sources for ranking history

### 4. Post-Publish Engagement Reporter
- **Area:** Content Distribution / Analytics
- **What to automate:** 24 hours after each Instagram/TikTok post, agent reads engagement data (via manual paste or Buffer API) and generates a short "Post Report Card" — saves rate, reach, profile visits, and a one-line hypothesis on why it performed how it did. Appended to a running `output/Analytics/post-performance.md` log. Over time, reveals which hooks and formats convert.
- **Tool/MCP:** Buffer API or Later API + Claude analysis + filesystem write
- **Time saved:** ~1.5 hours/week of manual analytics review; more importantly, builds institutional knowledge about what works
- **Difficulty:** Medium — depends on Buffer/Later API access; the Claude synthesis layer is trivial

### 5. Daily Founder Energy + Output Correlation Tracker
- **Area:** Health / Habits / Productivity
- **What to automate:** Each evening, agent asks one question via a watched file or CLI prompt: "Energy today (1–5)?" It cross-references that with files modified in the repo (git log) and words written (file diff) to auto-calculate a "Founder Output Score." Weekly Sunday agent summarizes correlation: "Your best output days correlate with energy 4–5 and <3 hours of meetings." Surfaces patterns invisibly costing performance.
- **Tool/MCP:** Bash (git log, file diff) + filesystem (health log file) + Claude analysis
- **Time saved:** Not about time — about quality of decisions over the next 12 months
- **Difficulty:** Easy — entirely local, no external APIs needed
