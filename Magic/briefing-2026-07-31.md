## Agentic Flow Ideas

> Based on repo structure at `LS-Yoobin/Agentic-Marketor`. Five new ideas distinct from prior briefings.

### 1. Post-Trip Memory Capture Agent
- **Area:** Content / Personal Productivity
- **What to automate:** When Yoobin returns from a trip (detected by gap in location photos), an agent immediately generates a "Trip Memory Capture" prompt — pulls place names from photo metadata, asks 3 questions (best moment, what surprised you, what you'd tell a friend), and drafts a Bloggo-style narrative entry + a social post draft. Captures the memory before it fades, without requiring a full writing session.
- **Tool/MCP:** Claude Vision API + filesystem + Notion MCP + scheduled trigger on photo batch detection
- **Time saved:** ~2 hours per trip of staring at the blank page; eliminates the "6 months later" problem personally
- **Difficulty:** Medium — requires photo metadata parsing + Claude narrative prompt

### 2. App Store Review Alert + Response Draft Agent
- **Area:** Product / Customer Feedback
- **What to automate:** Daily scrape of Bloggo's App Store reviews (any new 1-5 star reviews since yesterday). For negative reviews: Claude drafts a response that's warm, specific, and addresses the root complaint. For positive reviews: extracts a key quote for potential testimonial use and logs it to `output/Research/testimonials.md`. Founder reviews every draft, approves or edits, then submits.
- **Tool/MCP:** App Store Connect API or RSS scrape + Claude + Notion MCP
- **Time saved:** ~3 hours/week once reviews start flowing; ensures no review goes unresponded
- **Difficulty:** Medium — App Store Connect API access needed; response drafting is easy Claude task

### 3. Weekly Content Performance Grader
- **Area:** Content / Analytics
- **What to automate:** Every Sunday, an agent reviews the past week's content output (carousels, reels, captions generated) against a simple rubric: brand voice compliance, hook quality (rate 1-5), estimated virality (based on hook type + trend alignment), and content pillar balance (are all 4 Yoobin pillars being hit?). Outputs a `briefings/content-grade-[date].md` with a score and 3 specific improvement notes for next week.
- **Tool/MCP:** Claude + filesystem read (output/ folder) + WebSearch (to check current trends)
- **Time saved:** 1.5 hours/week of self-audit; builds a feedback loop so content improves systematically
- **Difficulty:** Easy — Claude reads existing files and grades against rules already in CLAUDE.md

### 4. Founder Habit Streak Tracker + Weekly Digest
- **Area:** Health / Habits / Accountability
- **What to automate:** Yoobin drops a one-line daily check-in into a watched file (`Magic/daily.log`): "2026-07-31: sleep 7h, shipped: yes, workout: no, mood: 8". Agent tallies streaks weekly (build streak, workout streak, sleep average) and writes a Sunday digest to `Magic/week-[date]-habits.md`. Flags when streaks break, suggests a reset action. Gamifies the solo founder daily routine.
- **Tool/MCP:** Filesystem watch + Claude analysis + scheduled trigger
- **Time saved:** ~30 min/week of self-tracking friction; the accountability value is harder to quantify but keeps the ship moving
- **Difficulty:** Easy — pure file read + Claude pattern recognition

### 5. Investor / Storytelling Arc Agent
- **Area:** Fundraising / Narrative
- **What to automate:** Monthly, an agent reads all briefings from the past 30 days and generates a "Founder Narrative Arc" summary — a timeline of key decisions, pivots, milestones, and emotional highs/lows written in a story format. Outputs to `output/narrative-arc-[month].md`. This is the raw material for: pitch decks, press stories, podcast appearances, and investor updates — all in one automated pass.
- **Tool/MCP:** Claude + filesystem (reads Magic/ folder) + Notion MCP for publishing
- **Time saved:** ~4 hours/month of narrative assembly; the compounded story also becomes the moat (authentic founder journey documented in real time)
- **Difficulty:** Easy — Claude reads existing briefing files and synthesizes; no external APIs needed
