## Agentic Flow Ideas

> Five new automation ideas for Yoobin's workflow as a solo founder building Bloggo + personal brand.

### 1. Auto Caption + Hashtag Writer (Post-Carousel)
- **Area:** Content Distribution
- **What:** After each morning's carousels are saved to `output/Carousels/`, an agent reads the `.brief` block in each HTML file, generates 3 caption variants (short/medium/long) + an optimized hashtag set tuned to September 2026 trending terms. Saves a `.captions.md` file alongside each carousel.
- **Tool/MCP:** Claude + WebSearch (trending hashtags) + filesystem write
- **Time saved:** ~3–4 hours/week — eliminates the most tedious post-generation step
- **Difficulty:** Easy — already have carousel files with `.brief` sections; just needs a triggered Claude task reading those sections

### 2. Beta Tester Feedback Digest
- **Area:** Product / Research
- **What:** Every 48 hours, agent scans a designated email folder or TestFlight feedback inbox, extracts all user mentions, groups by theme (bug / feature / praise / confusion), and writes a ranked digest to `output/Research/beta-feedback-[date].md`. Keeps Yoobin close to the product without spending 2 hours/week reading raw feedback.
- **Tool/MCP:** Gmail MCP or email API + Claude analysis + filesystem write
- **Time saved:** ~2 hours/week, more importantly surfaces signal from noise
- **Difficulty:** Medium — depends on connecting email MCP; analysis layer is easy

### 3. OpenAI / Big Tech News Reaction Content Generator
- **Area:** Content / Newsjacking
- **What:** When a major AI or photo app acquisition/launch drops (like today's OpenAI + Glass Imaging news), agent detects it in morning briefing, auto-drafts 2–3 reactive social posts from Bloggo's privacy angle ("We built the opposite: AI that stays on your phone."). Adds to `output/Content/reactive-[date].md` within 30 minutes of the briefing running.
- **Tool/MCP:** WebSearch + Claude + filesystem write
- **Time saved:** ~1.5 hours/week; more importantly captures the 24-hour virality window of news cycles
- **Difficulty:** Easy — already have the morning briefing agent; just add a reactive content output step

### 4. Weekly App Store Review Sentiment Tracker
- **Area:** Research / Competitive Intelligence
- **What:** Every Monday, agent searches for fresh App Store reviews of Bloggo's top 3 competitors (Polarsteps, Day One, Journey). Extracts 1-star and 2-star complaints, clusters by theme, appends to `output/Research/competitor-gaps-tracker.md`. Running tracker reveals whether competitor weaknesses are growing or resolving — directly feeds Bloggo's differentiation messaging.
- **Tool/MCP:** WebSearch (App Store review scraper) + Claude + filesystem append
- **Time saved:** ~2.5 hours/week of manual research
- **Difficulty:** Medium — App Store scraping requires a creative workaround (search for review aggregator sites or use manual paste option)

### 5. Founder Daily Output Log (Auto-Summary)
- **Area:** Productivity / Reflection
- **What:** At end of each day, Yoobin drops a 2-3 line note into `Magic/daily-log.txt` (what shipped, what was stuck, what decision was made). Agent reads the last 7 entries every Sunday, generates a "Week in Review" summary to `Magic/week-[date].md` with: streak of productive days, what category of work dominated (product vs. content vs. admin), and one pattern observation. Builds a longitudinal record of founder momentum.
- **Tool/MCP:** Filesystem watch + Claude analysis + scheduled trigger
- **Time saved:** 20 min/day of journaling friction; surfaces patterns that prevent founder burnout
- **Difficulty:** Easy — just a file watch + minimal Claude summarizer; no external APIs needed
