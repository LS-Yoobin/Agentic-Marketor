## Agentic Flow Ideas

> Five ideas distinct from all previous briefings. Based on the `ls-yoobin/Agentic-Marketor` repo structure and Yoobin's role as a solo co-founder building Bloggo + a personal brand.

### 1. Privacy News Reactive Content Agent
- **Area:** Content Strategy / Distribution
- **What:** Monitors tech news daily for any story about photo privacy breaches, AI data scandals, Big Tech photo-access controversies, or on-device AI developments. When one surfaces, agent auto-drafts a 3-slide Bloggo reactive carousel — "here's why we built differently" — and drops it to `docs/Marketing/Idea Inbox.md` within 1 hour. Timing reactive content to news cycles is how small brands punch above their weight.
- **Tool:** WebSearch + Claude + filesystem write
- **Time saved:** 2–3 hours/week monitoring + 1 hour reactive drafting
- **Difficulty:** Easy — WebSearch trigger + Claude carousel draft + file append

### 2. App Store Review → Social Proof Pipeline
- **Area:** Product / Content
- **What:** Reads new App Store reviews each morning via Appbot or AppFollow API. For 5-star reviews: extracts the most quotable sentence and appends it to a `output/Content/social-proof-bank.md` file for use in carousels and ads. For 1–3 star reviews: drafts a warm, brand-voice response for Yoobin to approve in one click. Turns every review into either a marketing asset or a handled problem.
- **Tool:** Appbot/AppFollow API + Claude + filesystem write
- **Time saved:** 3–4 hours/week; review management goes from open tab to resolved file
- **Difficulty:** Medium — needs Appbot/AppFollow API key; Claude extraction layer is straightforward

### 3. Weekly Content Execution Audit Agent
- **Area:** Content Analytics / Accountability
- **What:** Every Sunday at 9PM, agent reads the Notion Content Engine database (via Notion MCP), counts ideas added vs. actually published that week, and writes a "content execution rate" report to `Magic/content-audit-[date].md`. Flags any idea sitting unactioned for >14 days. Adds a single line: "You shipped X/Y ideas this week (Z%). Here's what's stale."
- **Tool:** Notion MCP + Claude + filesystem write
- **Time saved:** 1–2 hours/week of manual tracking; more importantly, creates accountability pressure
- **Difficulty:** Easy — Notion MCP already in scope; simple Claude analysis loop

### 4. Git-Commit → Building-in-Public Post Drafter
- **Area:** Social Distribution / Building in Public
- **What:** Post-commit hook in the `Agentic-Marketor` repo fires a Claude agent each time code is committed. Agent reads the commit message and diff summary, writes 3 tweet/Reel-caption variants in Yoobin's voice ("here's what I built today"), and saves them to `output/Content/bip-posts-[date].md`. One review-and-post becomes the distribution action.
- **Tool:** Git post-commit hook + Claude + filesystem write
- **Time saved:** 2 hours/week — eliminates the "I built something cool but never posted about it" trap
- **Difficulty:** Easy — post-commit hooks work in this repo; prompt just needs Yoobin's voice well-captured

### 5. Travel Photo Metadata Analyzer (Product Demo Generator)
- **Area:** Product QA / Content
- **What:** Weekly agent takes a small set of sample travel photos from `docs/Assets/` (already in the repo), runs EXIF/GPS metadata analysis via Python Pillow, outputs a "what Bloggo would find in this camera roll" mock report, and saves it to `output/Content/demo-trip-brief-[date].md`. Gives Yoobin a fresh, realistic "demo scenario" each week to use in content — without manually running the app. Side benefit: validates the metadata-parsing logic still works correctly.
- **Tool:** Python (Pillow for EXIF) + Claude analysis + filesystem write
- **Time saved:** 3 hours/week for product demo content creation; 0 manual iOS sim setup required
- **Difficulty:** Medium — Pillow already likely available; needs a sample photo set with real GPS data
